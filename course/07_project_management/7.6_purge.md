# Exercise 7.6: Purge unused data

**Goal.** Clean a model of everything it does not use.

## What you build

- Open `datasets/bloated_model.ifc`.
- Remove unused types, materials and profiles, and empty groups. Keep the column types of the project catalogue (4.2).
- Save as purged_model.ifc.

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## Check your work

Save or export your work as `purged_model.ifc`, then run:

```
python -m bimcheck 7.6 purged_model.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Old types, test materials and empty groups pile up in every project. They make files bigger and, worse, end up in schedules and type lists that others rely on.
