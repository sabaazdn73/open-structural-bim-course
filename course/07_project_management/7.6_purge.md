# Exercise 7.6: Purge unused data

**Goal.** Clean a model of everything it does not use.

## What you build

- Open `datasets/bloated_model.ifc`.
- Remove unused types, materials and profiles, and empty groups. Keep the column types of the project catalogue (4.2): a one-click 'purge all unused types' would delete them too, so remove the unused types one by one.
- Save as purged_model.ifc.

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

FreeCAD 1.1 has no purge command, and in a native IFC document the tree shows only what the elements use: unused types, materials, profiles and empty groups are in the file but not in the tree. You remove them with the IfcOpenShell library that ships with FreeCAD.

1. Copy `datasets/bloated_model.ifc` to your work folder and open the copy: File > Open with **All individual IFC objects**, **Load the shape (slower)**, **Locked (IFC objects only)**.
2. View > Panels > Python Console. Change the path of the catalogue (the types you keep) and run:
   ```python
   import ifcopenshell.api, ifcopenshell.util.element as ue
   f = FreeCAD.ActiveDocument.Proxy.ifcfile
   keep = [r.split(",")[0] for r in open("/path/to/course/datasets/column_types.csv").read().splitlines()[1:]]
   for t in f.by_type("IfcElementType"):
       if not ue.get_types(t) and t.Name not in keep:
           print("type", t.Name); ifcopenshell.api.run("root.remove_product", f, product=t)
   for m in f.by_type("IfcMaterial"):
       if f.get_total_inverses(m) == 0:
           print("material", m.Name); ifcopenshell.api.run("material.remove_material", f, material=m)
   for p in f.by_type("IfcProfileDef"):
       if f.get_total_inverses(p) == 0:
           print("profile", p.ProfileName); f.remove(p)
   for g in f.by_type("IfcGroup"):
       if not any(r.RelatedObjects for r in g.IsGroupedBy):
           print("group", g.Name); ifcopenshell.api.run("group.remove_group", f, group=g)
   FreeCAD.ActiveDocument.Modified = True
   ```
3. The console lists what it removed: two types (Temp Beam, Old Column 250x250), two materials, one profile and one group.
4. Read the list before you save. Types used by elements and the catalogue types stay.
5. File > Save IFC File As…, `purged_model.ifc`.

## In Bonsai

Bonsai's **Purge Data** panel removes unused data class by class. Its **Purge Unused Types** button would also remove the catalogue column types from 4.2 that no column uses yet, so you remove the two old types by hand.

1. Open `datasets/bloated_model.ifc` and save your copy as `purged_model.ifc`.
2. Pick the **Column Tool** and open its **Type Manager**. Click the gear next to **Old Column 250x250** and choose **Delete Type**.
3. Pick the **Beam Tool**, open its **Type Manager** and delete **Temp Beam** the same way.
4. Go to **Quality and Coordination > Quality Control > Purge Data** and open it.
5. Click **Purge Unused Profiles**. Bonsai removes the profile "Unused 200x200" that nothing uses.
6. On the **Material** row, click **Purge Unused**. Bonsai removes Concrete C20/25 (old) and Steel S235.
7. Go to **Project Overview > Grouping and Filtering > Groups**, click the pencil (**Load Groups**), click the empty group **Temp selection** and click **X** (**Remove Group**).
8. Check that the columns and the four catalogue column types are still there.
9. Save with **File > Save IFC Project**.

## Check your work

Save or export your work as `purged_model.ifc`, then run:

```
python -m bimcheck 7.6 purged_model.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Old types, test materials and empty groups pile up in every project. They make files bigger and, worse, end up in schedules and type lists that others rely on.
