# Exercise 7.1: Phases: existing, demolish, new

**Goal.** Mark what exists, what is demolished and what is new in a renovation model.

## What you build

- Open `datasets/renovation_model.ifc`: an existing one-bay frame.
- Elements named E-... : Status **EXISTING**. Beam D-1/AB: Status **DEMOLISH**.
- Add a new beam **N-B1** in place of D-1/AB: 300 x 600, x 0.2 to 5.8 on grid 1, +2.750 to +3.350, Status **NEW**.
- Save as renovation_model.ifc (your copy).

The numbers of section 7 that are not in the [project brief](../../brief/README.md) are given above.

## In FreeCAD

1. Copy `datasets/renovation_model.ifc` to your work folder and open the copy: File > Open…, with **All individual IFC objects**, **Load the shape (slower)** and **Locked (IFC objects only)** in IFC Import Options.
2. Select the existing columns E-A1, E-B1, E-A2, E-B2. Manage > Manage IFC Properties. **Add property set** > **Column Common** (Pset_ColumnCommon).
3. Pset_ColumnCommon in FreeCAD 1.1.3 has no Status entry: with the property set selected, **Add property** > **Label**, rename it `Status` and set `EXISTING`. Press OK.
4. Do the same for the beams E-2/AB, E-A/12 and E-B/12 with **Beam Common**, and for the slab E-S1 with **Slab Common**: Status `EXISTING`.
5. Select beam D-1/AB: Beam Common, Status `DEMOLISH`.
6. The new beam: right-click **Level 1** and choose **Make Active Container**. 3D/BIM > Beam, **Width** `300 mm`, **Height** `600 mm`, **Global** ticked, points 200, 0, 3050 and 5800, 0, 3050 (mid-depth of +2.750 to +3.350). In a locked IFC document FreeCAD turns the new beam into an IfcBeam a moment later.
7. Rename it `N-B1`. If it is not under Level 1 in the tree, drag it there.
8. Give N-B1 Beam Common with Status `NEW`, as in step 3.
9. File > Save IFC File As…, `renovation_model.ifc` in your work folder.

## In Bonsai

Bonsai records phases with the IFC Status property. The **Status** panel writes it into each element's common property set (Pset_ColumnCommon, Pset_BeamCommon...) and can show or hide elements by status.

1. Open `datasets/renovation_model.ifc` with **File > Open IFC Project** and save your copy with **File > Save IFC Project As...** as `renovation_model.ifc` in your work folder.
2. Go to **Costing and Scheduling > Status** and click **Enable Status Filters**. The panel lists NEW, EXISTING, DEMOLISH, TEMPORARY and the others.
3. Select every element whose name starts with E- (columns E-A1 to E-B2, beams E-2/AB, E-A/12, E-B/12, slab E-S1). In the Outliner, type `E-` in the filter field and select the results.
4. In the **Status** panel, click the brush icon (**Assign Status**) on the **EXISTING** row.
5. Select beam **D-1/AB** and click the brush icon on **DEMOLISH**.
6. Model the new beam. Add an **IfcRectangleProfileDef** `RC 300x600` (**XDim** `0.30`, **YDim** `0.60`) in **Geometry and Materials > Profiles**, then a beam type `RC Beam 300x600` with the **Beam Tool** (as in 2.4).
7. Make **Level 1** the default container, set **Axis** top centre, click **Add**, draw a beam along X and press Enter.
8. Set **Location** `0.2`, `0`, `3.35` and **Length** `5.6`, **Update**. The beam runs between E-A1 and E-B1 from +2.750 to +3.350. Name it `N-B1`.
9. With N-B1 selected, click the brush icon on **NEW**.
10. Use the eye icons in the **Status** panel to hide DEMOLISH, then EXISTING, and check what remains.
11. Save with **File > Save IFC Project**.

## Check your work

Save or export your work as `renovation_model.ifc`, then run this from the course folder:

```
python -m bimcheck 7.1 renovation_model.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Most structural work is on existing buildings. IFC records phases with the Status property (NEW, EXISTING, DEMOLISH, TEMPORARY) in each element's common property set, which drawings and quantities can filter by.
