# Exercise 7.2: Design options: compare two versions

**Goal.** Save two design options and compare them.

## What you build

- Option A: your TB-01 model as it is (sections 1 and 2).
- Option B: the same model with beam **B-2/BC** changed to 400 wide x 500 deep, still hung from the slab soffit (+2.850 to +3.350).
- Save them as option_A.ifc and option_B.ifc, then compare them with your program's IFC diff tool.

The numbers of section 7 that are not in the [project brief](../../brief/README.md) are given above.

## In FreeCAD

1. Open `tb01.FCStd`. Option A is the frame of sections 1 and 2 as it is.
2. Select TB-01 Training Building. File > Export…, Industry Foundation Classes, `option_A.ifc`. With **Store IFC unique ID in FreeCAD objects** on (Edit > Preferences > Import-Export > IFC Export, on by default) every element now keeps its IFC id.
3. File > Save Copy, `option_B.FCStd`. File > Open `option_B.FCStd`.
4. In option_B select beam **B-2/BC**. In the Data tab set **Width** `400 mm` and **Height** `500 mm`.
5. The beam grows around its axis, so move the axis down to keep the top at the soffit: **Placement > Position > z** `3100 mm` (the beam now runs from +2.850 to +3.350).
6. Export option_B: select TB-01 Training Building, File > Export…, `option_B.ifc`.
7. Compare: keep only `tb01.FCStd` and `option_B.FCStd` open, make tb01 the active document, and use Utils > IFC Diff (the first of the two IFC Diff entries). Answer Yes to the question.
8. FreeCAD matches the elements by their IFC id, selects what changed and reports it in the Report view (View > Panels > Report View): only B-2/BC.
9. Keep both IFC files: they are the two options.

## In Bonsai

1. Open your TB-01 model. Choose **File > Save IFC Project As...** and save it as `option_A.ifc`. Do not change anything in it.
2. Choose **File > Save IFC Project As...** again and save it as `option_B.ifc`. You are now working in option B.
3. Add an **IfcRectangleProfileDef** `RC 400x500` (**XDim** `0.40`, **YDim** `0.50`) in **Geometry and Materials > Profiles**.
4. With the **Beam Tool**, open the **Type Manager** and click **Create New IfcBeamType**: **Name** `RC Beam 400x500 downstand`, **Predefined Type** BEAM, **Representation** Extruded Profile, **Profile** RC 400x500.
5. Select beam **B-2/BC**. In **Object Information > Object > Type**, click the pencil (**Enable Editing Type**), choose IfcBeamType and **RC Beam 400x500 downstand**, and click the check mark (**Assign Type**).
6. Bonsai rebuilds the beam with the new profile and keeps its axis at the top centre, so it still hangs from +3.350 and now reaches +2.850, 400 wide.
7. Save with **File > Save IFC Project**.
8. Go to **Quality and Coordination > Quality Control > Diff**. Set **Active File** to the new file (option B is open) and pick `option_A.ifc` as the **Old IFC File** with the folder icon.
9. Click **Execute IFC Diff** and save the report as `diff.json`. Click the eye icon (**Visualise Diff**): only B-2/BC is coloured as changed.
10. Open `diff.json` in a text editor: it lists one changed element and what changed.

## Check your work

Save your two options as `option_A.ifc` and `option_B.ifc`, then run this from the course folder:

```
python -m bimcheck 7.2 option_A.ifc option_B.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Revit keeps options inside one file; in open BIM you keep each option as its own file (or Git branch) and compare them. The comparison is the deliverable: exactly what changed, and nothing else.
