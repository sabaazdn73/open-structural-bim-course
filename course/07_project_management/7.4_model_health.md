# Exercise 7.4: Model health: fix the warnings

**Goal.** Find and fix the problems in a model that looks fine.

## What you build

- Open `datasets/unhealthy_model.ifc`.
- It has four problems: a duplicate column, an element that belongs to no level, an element without a material, and an element without a name. Find them with your program's checking tools (or a short script where it has none) and fix them.
- Save as fixed_model.ifc.

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

Manage > Preflight Checks tests classic FreeCAD objects only; on a native IFC file it finds nothing. FreeCAD 1.1 has no warnings list for IFC files, so you run the same four checks as a short script.

1. Copy `datasets/unhealthy_model.ifc` to your work folder and open the copy: File > Open with **All individual IFC objects**, **Load the shape (slower)**, **Locked (IFC objects only)**, and tick **Preload materials**.
2. View > Panels > Python Console. Run:
   ```python
   import ifcopenshell.util.element as ue, ifcopenshell.util.placement as up
   f = FreeCAD.ActiveDocument.Proxy.ifcfile
   seen = {}
   for e in f.by_type("IfcBuildingElement"):
       key = (e.is_a(), tuple(up.get_local_placement(e.ObjectPlacement)[:3, 3].round(3)))
       if key in seen:
           print("duplicate:", e.Name, "#", e.id(), "same place as #", seen[key].id())
       seen[key] = e
       if not ue.get_container(e):
           print("no level:", e.Name, "#", e.id())
       if not ue.get_material(e):
           print("no material:", e.Name, "#", e.id())
       if not (e.Name or "").strip():
           print("no name:", e.is_a(), "#", e.id())
   ```
   It lists four problems. The number after # is the element's **Step Id**, shown in the Data tab of each object.
3. Duplicate column: the line `duplicate: C-B2 # ...` gives the Step Id of the extra copy. Select the C-B2 with that Step Id and press Delete. FreeCAD removes it from the IFC file.
4. Beam without a level: drag **B-2/CD** onto **Level 1** in the tree.
5. Element without a material: select the slab **S-L1**, Manage > Material, pick **Concrete C30/37** and press OK.
6. Element without a name: the wall shows in the tree as **_IfcWall**. Rename it `W-Core-E` (F2); FreeCAD writes the label as the IFC name.
7. Run the script of step 2 again: it prints nothing.
8. File > Save IFC File As…, `fixed_model.ifc`.

## In Bonsai

Each of the four problems can be found with a search query in Bonsai. The queries use the IfcOpenShell selector syntax.

1. Open `datasets/unhealthy_model.ifc` and save your copy as `fixed_model.ifc` (**File > Save IFC Project As...**).
2. In **Project Overview > Grouping and Filtering > Search**, click the funnel (**Edit Filter Query**). For each query below, deselect all (Alt+A), type the query, click OK and click **Search**:
   - `IfcColumn, IfcBeam, IfcSlab, IfcWall, location=NULL` finds the element in no level: beam B-2/CD.
   - `IfcColumn, IfcBeam, IfcSlab, IfcWall, material=NULL` finds the element without a material: the slab.
   - `IfcColumn, IfcBeam, IfcSlab, IfcWall, Name=""` finds the element without a name: a core wall.
3. For the duplicate, look at **Spatial Decomposition**: click Level 0 and the element list shows 13 columns instead of 12. In the Outliner, filter for `C-`: one column appears twice (Blender adds ".001" to the second name).
4. Fix the duplicate: select the column with ".001", press X and choose **IFC Delete**.
5. Fix the beam: select B-2/CD, open **Object Information > Object > Spatial Container**, click the pencil (**Enable Editing Container**), choose **Level 1** and click the check mark (**Assign Container**).
6. Fix the slab: select it, open **Geometry and Materials > Object Materials**, choose IfcMaterial and **Concrete C30/37**, and click **+** (**Assign Material**).
7. Fix the wall: it sits on the east side of the core (x 10.25 to 10.5). In **Object Attributes**, click **Edit**, set **Name** `W-Core-E` and click **Save Attributes**.
8. Run the three searches again: each finds nothing. Click Level 0 in **Spatial Decomposition**: 12 columns.
9. Save with **File > Save IFC Project**.

## Check your work

Save or export your work as `fixed_model.ifc`, then run:

```
python -m bimcheck 7.4 fixed_model.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Revit lists these as warnings. Open tools let you run the same checks (and your own, written as IDS rules or scripts). A model with silent duplicates doubles concrete in the quantities and confuses everyone downstream.
