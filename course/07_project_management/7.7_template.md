# Exercise 7.7: Project library (template)

**Goal.** Save a template that the next project can start from.

## What you build

- A file with the three types of 4.1 and the materials Concrete C30/37, Concrete C25/30 and A500.
- No placed elements (no columns, beams...): only definitions. Levels may be included.
- Save as template.ifc.

The numbers of section 7 that are not in the [project brief](../../brief/README.md) are given above.

## In FreeCAD

1. Open your `tb01.ifc` of section 4 (File > Open…, **All individual IFC objects**, **Load the shape (slower)**, **Locked (IFC objects only)**).
2. File > Save IFC File As…, `template.ifc`, so that the next steps do not touch tb01.ifc.
3. In the tree, select every placed element: the columns, beams, core walls, slab, stair, pad footings, pile cap, piles and rebars (open each level and Ctrl+click or Shift+click).
4. Press Delete. FreeCAD removes the elements from the IFC file. The levels, the grid, the types (RC Column 400x400, RC Beam 300x350 downstand, Pad Footing 1800x1800x600 and the catalogue column types) and the materials stay, because nothing deletes them with the elements.
5. File > Save IFC File (Ctrl+S).
6. Check with `python -m bimcheck 7.7 template.ifc`: the materials Concrete C30/37, Concrete C25/30 and A500 must be listed, and no placed element may be left.

## In Bonsai

A Bonsai project library is any IFC file you append types from. Your template starts empty and takes its types from `tb01.ifc`, with their profiles and materials.

1. Choose **File > New IFC Project > New Metric (m) Project**. Rename the project `TB-01 Structural Template` in **Object Attributes**.
2. In **Spatial Decomposition**, either delete **My Storey** (click it and **X**, **Delete Container**) or rename it and add the five levels as in 1.2. Any level you keep must have a name from the brief.
3. Go to **Project Overview > Project Setup > Project Library**. Click the folder icon (**Select Library File**) and pick your `tb01.ifc`.
4. Open the **IfcColumnType** category in the list and click the append icon (**Append Library Element**) next to **RC Column 400x400**.
5. Append **RC Beam 300x350 downstand** from IfcBeamType and **Pad Footing 1800x1800x600** from IfcFootingType. Their profiles and materials (Concrete C30/37, Concrete C25/30) come with them.
6. In **Geometry and Materials > Materials**, check the list and add `A500` (Category `steel`) with **+** (**Add Material**). Add any concrete that is missing.
7. Do not place any element. The template holds only definitions.
8. Save with **File > Save IFC Project** as `template.ifc`.
9. Next time, start a project with **File > Open IFC Project** on a copy of `template.ifc`, or keep your project and append from the template in **Project Library**.

## Check your work

Save or export your work as `template.ifc`, then run this from the course folder:

```
python -m bimcheck 7.7 template.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Revit transfers project standards between files; open BIM keeps them in a library file that every new project starts from or loads types from. It is how an office keeps its standards consistent.
