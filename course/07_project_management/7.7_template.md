# Exercise 7.7: Project library (template)

**Goal.** Save a template that the next project can start from.

## What you build

- A file with the three types of 4.1 and the materials Concrete C30/37, Concrete C25/30 and A500.
- No placed elements (no columns, beams...): only definitions. Levels may be included.
- Save as template.ifc.

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## Check your work

Save or export your work as `template.ifc`, then run:

```
python -m bimcheck 7.7 template.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Revit transfers project standards between files; open BIM keeps them in a library file that every new project starts from or loads types from. It is how an office keeps its standards consistent.
