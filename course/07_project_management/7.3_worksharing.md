# Exercise 7.3: Worksharing with Git

**Goal.** Put the model under version control so a team can work on it.

## What you build

- Create a Git repository for your TB-01 work.
- Commit the IFC model at least twice, with messages that say what changed (for example 'Levels and grid' and 'Columns, walls, slab and beams').
- Commit the IFC file itself, not only the FreeCAD or Blender file.

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

FreeCAD has no Git panel in 1.1 (the Git tool of the WebTools add-on is optional); use Git on the command line.

1. Install Git (git-scm.com) and set your name once: `git config --global user.name "Your Name"` and `git config --global user.email "you@example.com"`.
2. Make a folder for the model and a repository in it: `mkdir tb01_repo`, `cd tb01_repo`, `git init`.
3. Export `tb01.ifc` from the model as it was after section 1 into `tb01_repo` (or copy the file there).
4. `git add tb01.ifc` and `git commit -m "Levels and grid"`.
5. Export `tb01.ifc` again after section 2 into the same folder, over the old file.
6. `git commit -am "Columns, core walls, slab and beams"`.
7. `git log --oneline` shows the two commits; `git diff HEAD~1 --stat` shows that tb01.ifc changed.
8. You may add `tb01.FCStd` too, but the IFC file must be committed: it is the shared model.
9. Check with `python -m bimcheck 7.3 path/to/tb01_repo`.

## In Bonsai

Bonsai has a Git panel. It needs Git installed on your computer (git-scm.com); on Windows the panel offers **Install Git**.

1. Put `tb01.ifc` in its own folder, for example `TB01-work`. Do not make your whole user folder a repository.
2. If you have never used Git on this computer, set your name once in a terminal: `git config --global user.name "Your Name"` and `git config --global user.email "you@example.org"`.
3. Open `tb01.ifc`. The best moment is right after section 1 (levels and grid); if you are further on, start now and commit after your next change.
4. Go to **Project Overview > Project Info > Git** and click **Create 'TB01-work' repository**.
5. Click **Add 'tb01.ifc' to repository**. Bonsai makes the first commit, "Added tb01.ifc".
6. Do the next part of the work (for example section 2, or the quantities of 7.8) and save with **File > Save IFC Project**. The Git panel says "Saved changes have not been committed".
7. Click **Show uncommitted changes** to see the new elements in colour.
8. Type a message that says what changed, for example `Columns, walls, slab and beams`, and click **Commit changes**.
9. Repeat after each section. The list at the bottom of the panel shows every commit with its message and date.
10. Run the checker on the folder: `python -m bimcheck 7.3 TB01-work`.

## Check your work

Save or export your work as `a Git repository`, then run:

```
python -m bimcheck 7.3 path/to/your/repository
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Revit worksharing locks parts of a central model. In open BIM the IFC file is text, so Git can store every version, show who changed what, and merge work from two people. Bonsai has Git built in; with FreeCAD you use Git directly.
