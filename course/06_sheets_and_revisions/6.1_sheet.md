# Exercise 6.1: Sheet S-101 with a title block

**Goal.** Place the framing plan on a sheet with a title block.

## What you build

- Sheet number **S-101**, title **LEVEL 1 FRAMING PLAN**, scale **1:100**, project **TB-01 Training Building**.
- Place the Level 1 framing plan on it. If your title block template has no field for the project name, add it to the template.
- Export as SVG or PDF.

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

The sheet is drawn around the plan of 5.1 at 1:100, so one flattened SVG holds the plan, the frame and the title block with all texts kept as text. An A3 sheet (420 x 297 mm) at 1:100 is 42000 x 29700 model millimetres.

1. Open `tb01.FCStd`. Keep the annotation scale at `1:100`.
2. 2D Drafting > Rectangle with **Global** ticked: corner -6000, -9000, 0 and opposite corner 36000, 20700, 0. This is the sheet border around the plan.
3. Draw the title block in the lower right corner: a rectangle from 19000, -9000, 0 to 36000, -4000, 0.
4. Annotation > Text in the title block, one line each: `TB-01 Training Building`, `LEVEL 1 FRAMING PLAN`, `Sheet S-101`, `Scale 1:100`.
5. Select the four texts and set **Font Size** `250 mm` (`350 mm` for the title) in the View tab.
6. Select the plan (Viewed lines, Cut lines, dimensions, labels, Grid A-D, Grid 1-3), the two rectangles and the title block texts.
7. File > Export…, **Flattened SVG (*.svg)**, save as `sheet.svg`.
8. Open `sheet.svg` and check that the plan sits inside the border and clear of the title block.

If this does not work: FreeCAD's TechDraw sheets (Annotation > New Page with a template such as A3_Landscape_TD.svg, then Annotation > New View) fill the title block from template fields, and their texts export as text; in our tests with FreeCAD 1.1.3 the texts inside the BIM view itself did not, so the checker could not see the grid bubbles on such a sheet.

## In Bonsai

A Bonsai sheet is an SVG layout: a title block template plus the drawings you place on it. The default title blocks fill in the sheet number (Identification), the sheet title (Name) and the revision. The view title under each drawing shows the drawing name and its scale. The project name is not in the default title block, so you add it to the project's copy of the template.

1. Create the plan drawing again if you changed the model (**Create Drawing**, 5.1). A drawing must exist as an SVG before it can go on a sheet.
2. Go to **Drawings and Documents > Sheets** and click the import icon (**Load Sheets**). Choose the title block **A3** and click **+** (**Add Sheet**).
3. With the new sheet active, click the pencil (**Edit Sheet / Drawing**). Set **Identification** `S-101` and **Name** `LEVEL 1 FRAMING PLAN` and confirm.
4. In **Drawings and Documents > Drawings**, click **LEVEL 1 FRAMING PLAN** in the list. Back in **Sheets**, with S-101 active, click **Add Selected Drawing To Sheet** (the image icon).
5. When you added the sheet, Bonsai copied the title block to `layouts/titleblocks/A3.svg` next to `tb01.ifc`. Open that copy in Inkscape or a text editor, replace the text `COMPANY` with `TB-01 Training Building` and save it. Keep the `{{Identification}}`, `{{Name}}` and `{{Revision}}` fields.
6. In **Sheets**, click the output icon (**Create Sheets**). Bonsai writes `sheets/S-101 - LEVEL 1 FRAMING PLAN.svg` with the title block and the plan inside it as text and lines.
7. Open the sheet with the eye icon (**Open Sheet**) and check: S-101, LEVEL 1 FRAMING PLAN, the project name, the grid bubbles, and 1:100 in the view title.
8. Copy the file as `sheet.svg` for the checker. For a PDF as well, set **SVG to PDF Command** in the Bonsai preferences (for example Inkscape); Bonsai then writes the PDF next to the SVG.

## Check your work

Save or export your work as `sheet.svg`, then run this from the course folder:

```
python -m bimcheck 6.1 sheet.svg
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Sheets are what leaves the office. A title block filled from the model's data (project, sheet number, scale) avoids the classic error of an issue with last week's sheet number.
