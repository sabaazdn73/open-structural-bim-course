# Exercise 5.1: Level 1 framing plan with grids and dimensions

**Goal.** Produce the Level 1 framing plan from the model and export it as SVG (or PDF).

## What you build

- A plan view of Level 1 showing the grid with its bubbles (A to D, 1 to 3), the columns and beams cut just below the slab, and the slab openings where your plan cut shows them.
- Dimension the bays (6000 x 3 along X, 7000 x 2 along Y) and the overall sizes (18000 and 14000).
- Export as SVG (best) or PDF with text kept as text.

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

Drawings come from the classic model `tb01.FCStd` of sections 1 to 3. You cut it with a section plane, turn the cut into a BIM 2D drawing, annotate it with Draft tools and export it as a flattened SVG, which keeps every text as text.

1. Open `tb01.FCStd`. In the status bar at the bottom, set the Draft annotation scale to `1:100`.
2. Select Level 0 and Level 1 in the tree. Annotation > Section Plane. In the Data tab set **Placement > Position** 9000, 7000, 3200 and leave the angle at 0: a horizontal cut between the beam soffit (+3.000) and the slab soffit (+3.350), looking down. Rename it `Section Level 1 plan`.
3. With the section plane selected, Annotation > Create 2D Views > 2D Drawing. FreeCAD makes a drawing with **Viewed lines** and **Cut lines** laid flat on the ground plane. Rename it `Level 1 framing plan`.
4. Annotation > Horizontal Dimension, with **Global** ticked: 0, -2500, 0 to 6000, -2500, 0, then click below to place the line. Repeat for 6000 to 12000 and 12000 to 18000, and once more from 0 to 18000 at y -3500 for the overall size.
5. Annotation > Vertical Dimension: 0 to 7000 and 7000 to 14000 at x -2500, and 0 to 14000 at x -3500.
6. Select all dimensions and in the View tab set **Font Size** `250 mm` (the SVG exporter writes the font size as it is, and 1:100 needs 2.5 mm text).
7. Drag the dimensions into the drawing Level 1 framing plan in the tree.
8. Select Viewed lines, Cut lines, the dimensions and the two axis objects Grid A-D and Grid 1-3 (they carry the bubbles A to D and 1 to 3).
9. File > Export…, set the file type to **Flattened SVG (*.svg)** and save as `plan.svg`.
10. Open `plan.svg` in a web browser or Inkscape and check the bubbles and the dimensions 6000 and 7000 (FreeCAD writes them as 6000.00 mm).

If this does not work: Annotation > New Page and New View put the same section plane on a TechDraw sheet, but in our tests with FreeCAD 1.1.3 the SVG and PDF exported from TechDraw lost the texts of the BIM view, so the checker found no grid bubbles. Use the flattened SVG for the check.

## In Bonsai

Bonsai draws plans, sections and sheets as SVG files next to your IFC file, with text kept as text. Every drawing shows the grid axes and their bubbles without any extra step. The drawing panels only work on a saved project.

1. Save with **File > Save IFC Project**.
2. In the sidebar (N) > **View**, set **3D Cursor Location** to X `9`, Y `7`, Z `0`. Bonsai centres a new plan on the cursor.
3. Go to **Drawings and Documents > Drawings** and click the import icon (**Load Drawings**). In the first row choose **Plan** and **Level 1**, then click **+** (**Add Drawing**).
4. Double-click the new drawing in the list and rename it `LEVEL 1 FRAMING PLAN`. Click its camera icon (**Activate Drawing**).
5. Bonsai puts the plan camera 1.6 m above Level 1, which looks down on the top of the slab. Select the camera (IfcAnnotation/LEVEL 1 FRAMING PLAN in the Outliner) and set **Location Z** `3.3` in the sidebar **Item** tab. The cut now passes through the beams and the column heads; the slab is above the cut and is not drawn.
6. In **Drawings and Documents > Drawings > Active Drawing**, set **Width** `24`, **Height** `20` and **Scale** 1:100.
7. Pick the **Annotation Tool** in the toolbar and choose **Dimension** in its header. Click **Add** (Shift+A). Bonsai creates a two-point dimension near the cursor and opens it in Edit mode.
8. In the sidebar (N) > **Item**, switch the control point coordinates to **Global**. Select one point and type X `0`, Y `-3`; select the other and type X `6`, Y `-3`.
9. With the second point selected, press E, X, `6`, Enter, and again E, X, `6`, Enter. The chain now has points at x 0, 6, 12, 18 and shows 6.000 three times. Press Tab to leave Edit mode.
10. Add three more dimensions the same way: overall X from (0, -5) to (18, -5); chain Y at x = -3 through (-3, 0), (-3, 7), (-3, 14); overall Y from (-5, 0) to (-5, 14).
11. In the **Drawings** list, click the output icon (**Create Drawing**). Bonsai writes `drawings/LEVEL 1 FRAMING PLAN.svg` in the folder of `tb01.ifc` and opens it.
12. Copy that file as `plan.svg` for the checker, or give the checker its path. Do not print it to PDF from a browser: the checker needs the text.

## Check your work

Save or export your work as `plan.svg`, then run this from the course folder:

```
python -m bimcheck 5.1 plan.svg
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

The drawing is still the legal document on most projects. A plan cut from the model stays right when the model changes; a plan drawn by hand does not.
