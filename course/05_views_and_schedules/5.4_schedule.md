# Exercise 5.4: Concrete quantity schedule (CSV)

**Goal.** Schedule the concrete volume of every element and export it to CSV.

## What you build

- One row per element (or per class) with the element class and its volume in m3.
- Columns, beams, slab, walls, footings (pad and cap), piles.
- Export as CSV. The checker compares your totals with the volumes in your model (2% tolerance).

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

1. Open `tb01.FCStd`.
2. Manage > Schedule. The **Schedule Definition** panel opens. Set **Schedule name** `Concrete volumes`.
3. Press **Add Row** six times. In the **Description** column type `Columns`, `Beams`, `Slab`, `Walls`, `Footings and caps`, `Piles`. Keep the word "pile" out of the footing row: the checker sorts rows by the words in them.
4. In **Property** type `Shape.Volume` on every row, and in **Unit** type `m^3`.
5. Select the building **TB-01** in the tree, select all six rows and press **Add Selection**: the **Objects** column now names the building, so each row looks inside it.
6. In **Filter** type `IfcType:Column`, `IfcType:Beam`, `IfcType:Slab`, `IfcType:Wall`, `IfcType:Footing`, `IfcType:Pile`.
7. Press OK. The schedule computes the totals: columns 6.43, beams 10.84, slab 63.06, walls 9.21, footings and cap 39.33, piles 13.57 m³.
8. Double-click the schedule in the tree to open the panel again and press **Export**. Choose **Comma-separated values (*.csv)** and save as `schedule.csv`.
9. Check with `python -m bimcheck 5.4 schedule.csv tb01.ifc`. The piles in the IFC file are faceted, about 1.8 % smaller than the true cylinders in FreeCAD, which is inside the 2 % tolerance.

## In Bonsai

In Bonsai a quantity schedule is two steps: compute base quantities into the model, then export them with the spreadsheet tool. The quantity rule that uses IfcOpenShell geometry gives volumes for columns, beams, slabs, walls and footings, but not for piles, so you quantify the piles by hand.

1. Deselect all (Alt+A). Go to **Costing and Scheduling > Quantity Take-off**. The panel says "Quantifying All Objects".
2. Choose the rule **IFC4 Base Quantities - IfcOpenShell** and click **Perform Quantity Take-off**. Each element gets its Qto_...BaseQuantities set with NetVolume.
3. Select the four piles (Search `IfcPile`). In **Manual Quantification**, set **Calculator** IfcOpenShell, **Function** Volume: Net Volume, and type `Qto_PileBaseQuantities` and `NetVolume` in the two name fields. Click **Calculate Single Quantity**.
4. Go to **Quality and Coordination > Collaboration > Spreadsheet Import/Export**. Tick **Load from Memory** and open the settings (gear icon): **Format** csv.
5. Click the funnel (**Edit Filter Query**) and type `IfcColumn, IfcBeam, IfcSlab, IfcWall, IfcFooting, IfcPile`.
6. Click **Add CSV Attribute** three times and fill in each row (attribute, then header):
   - `class`, `Class`
   - `Name`, `Mark`
   - `/Qto_.*BaseQuantities/.NetVolume`, `Volume (m3)`
7. Click **Export IFC to CSV** and save as `schedule.csv`. Open it: one row per element with its class, mark and volume.
8. Do not add a column with the type name: the checker reads "Pile Cap" as a pile.
9. Save the model too (**File > Save IFC Project**): the checker compares the schedule with the volumes in `tb01.ifc`.

## Check your work

Save or export your work as `schedule.csv`, then run:

```
python -m bimcheck 5.4 schedule.csv tb01.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

This is the quantity takeoff an estimator does by hand from drawings, done in minutes from the model. It only works if the model is clean (exercise 2.5) and every element has its class right.
