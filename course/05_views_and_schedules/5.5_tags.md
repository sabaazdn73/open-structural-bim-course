# Exercise 5.5: Element marks and tags

**Goal.** Tag every column with its mark on the framing plan.

## What you build

- Every column is named by its mark (C-A1 ... C-D3) in the model (done in 2.1).
- Add a tag on the Level 1 framing plan for each of the 12 columns, reading the mark from the model.
- Export the plan again.

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

A Draft Label of type **Label** reads the label (the mark) of the object it points to, so it changes when you rename the column.

1. Open `tb01.FCStd` and check that the columns are named C-A1 ... C-D3 (exercise 2.1).
2. Keep the annotation scale at `1:100` (status bar).
3. Select column **C-A1** in the tree. Annotation > Label. In the task panel set **Label Type** to `Label`.
4. With **Global** ticked, click (or type) the target point on the column, then the end of the leader and the text position, a little to the upper right of the column. The tag shows `C-A1`.
5. Repeat for the other 11 columns, each time selecting the column first.
6. Select the 12 labels, set **Font Size** `250 mm` in the View tab and drag them into the drawing Level 1 framing plan.
7. Test the link: rename one column to `C-X`, see its tag change, then rename it back.
8. Export the plan again as in 5.1 (add the labels to the selection): File > Export…, **Flattened SVG (*.svg)**, `plan.svg`.
9. Check with `python -m bimcheck 5.5 tb01.ifc plan.svg`, using the `tb01.ifc` you saved in section 4.

## In Bonsai

1. In **Drawings and Documents > Drawings**, activate **LEVEL 1 FRAMING PLAN** (camera icon).
2. Deselect all and select the 12 columns (Search `IfcColumn`).
3. Pick the **Annotation Tool** and choose **Text** in its header. Click **Bulk Tag** (Shift+T). Bonsai adds one text at the centre of each column and links it to that column. The new tags are selected.
4. Press Shift+E (**Edit Text**). In the literal, replace "TEXT" with `{{Name}}`. The line below shows the current value, for example C-D3.
5. Still in the dialog, click the copy icon next to **Literals:** (**Copy Text To Selection**). All 12 tags now read `{{Name}}`. Click OK.
6. Move a tag off its column with G if it hides the column. Click the **Readjust** button (Shift+G) to put tags back over their columns.
7. Test it: rename a column, then create the drawing again. The tag follows the new name.
8. Click **Create Drawing** and copy `drawings/LEVEL 1 FRAMING PLAN.svg` as `plan.svg` again.

## Check your work

Save or export your work as `plan.svg`, then run:

```
python -m bimcheck 5.5 tb01.ifc plan.svg
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

A tag reads the model; a text label does not. When a column is renamed, the tag follows.
