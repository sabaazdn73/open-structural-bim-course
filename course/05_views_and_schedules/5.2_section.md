# Exercise 5.2: Section through grid 2

**Goal.** Cut a section through grid 2 and annotate the levels.

## What you build

- Section along grid 2 looking north, showing columns, beams, the slab and the footings.
- Level lines with names and elevations: Foundation -1.200, Level 0 +0.000, Level 1 +3.600.
- Grid bubbles A to D. Export as SVG or PDF.

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

1. Open `tb01.FCStd`. Keep the annotation scale at `1:100` (status bar).
2. Select Foundation, Level 0 and Level 1 in the tree. Annotation > Section Plane.
3. In the Data tab set **Placement > Angle** `90 °`, **Axis** 1, 0, 0 and **Position** 9000, 7000, 1000. The plane now stands on grid 2. Its arrows show the viewing direction: they must point north (+Y). If they point south, set the angle to `-90 °`. Rename it `Section grid 2`.
4. With the plane selected, Annotation > Create 2D Views > 2D Drawing. The section is laid flat on the ground plane: x stays x, and the height of the building becomes the drawing's y.
5. Draw the level lines with 2D Drafting > Line across the section at the heights of Foundation, Level 0 and Level 1. Look at where the footing undersides and the slab top fall in the 2D drawing to place them.
6. Annotation > Text next to each line: `Foundation -1.200`, `Level 0 +0.000`, `Level 1 +3.600`. FreeCAD 1.1 has no level tag for 2D drawings, so type the values and check them against the levels' Placement z.
7. Annotation > Text above each column line: `A`, `B`, `C`, `D` (the grid bubbles of the section).
8. Select the texts and set **Font Size** `250 mm` in the View tab. Drag them into the drawing Section grid 2.
9. Select Viewed lines, Cut lines, the level lines and all texts. File > Export…, **Flattened SVG (*.svg)**, save as `section.svg`.

## In Bonsai

1. Save the model. In the sidebar (N) > **View**, set **3D Cursor Location** to X `9`, Y `7`, Z `1.2`. A section camera is placed at the cursor, so it cuts along grid 2.
2. In **Drawings and Documents > Drawings**, choose **Section** and **North** in the first row and click **+** (**Add Drawing**). North means the camera looks towards +Y.
3. Rename the drawing `SECTION GRID 2` and click its camera icon (**Activate Drawing**).
4. In **Active Drawing**, set **Width** `24`, **Height** `8`, **Depth** `8` and **Scale** 1:100. The frame runs from x -3 to 21 and from z -2.8 to +5.2, so the footings and Level 1 are inside.
5. Bonsai adds a level line for every storey that the frame crosses, with its name and its elevation (for example "Level 1" and "RL +3.600"), and the grid lines A to D with their bubbles. You do not draw them.
6. Click **Create Drawing** (output icon). Bonsai writes `drawings/SECTION GRID 2.svg`.
7. Copy it as `section.svg` for the checker.

## Check your work

Save or export your work as `section.svg`, then run:

```
python -m bimcheck 5.2 section.svg
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Sections show what plans hide: levels, depths and how elements stack. Where your program has level tags, they read their values from the model and update when a level moves; otherwise type them and check them.
