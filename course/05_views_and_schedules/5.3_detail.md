# Exercise 5.3: Detail callout with annotation

**Goal.** Make a detail of footing F-A1 with notes.

## What you build

- A detail view (a callout, or an enlarged section at 1:20) of footing F-A1 with the column above.
- Title **TYPICAL COLUMN FOOTING DETAIL**.
- Notes: concrete **C25/30**, steel **A500**, bottom mesh **Ø16 @ 150** each way, **50 mm cover**.
- Export as SVG or PDF.

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

1. Open `tb01.FCStd`. Set the annotation scale in the status bar to `1:20`.
2. Select F-A1, C-A1 and the rebars of exercise 3.4. Annotation > Section Plane.
3. Set **Placement > Angle** `90 °`, **Axis** 1, 0, 0, **Position** 0, 0, -600: a vertical cut through the middle of F-A1 and C-A1. In the View tab set **Display Length** and **Display Height** to `3000 mm`, so the plane covers only the footing and the foot of the column. Rename it `Detail F-A1`.
4. With the plane selected, Annotation > Create 2D Views > 2D Drawing. Rename the drawing `Detail F-A1`.
5. Annotation > Text below the drawing: `TYPICAL COLUMN FOOTING DETAIL`.
6. Annotation > Text beside it, one note per text: `Concrete C25/30, exposure XC2`, `Steel A500`, `Bottom mesh Ø16 @ 150 each way`, `50 mm cover`. Annotation > Leader can point a note to the bars.
7. Set **Font Size** `60 mm` for the notes in the View tab (3 mm at 1:20). Drag them into the drawing.
8. Select Viewed lines, Cut lines and the texts. File > Export…, **Flattened SVG (*.svg)**, save as `detail.svg`.

## In Bonsai

Bonsai has no separate callout object. A detail is a drawing with a small frame and a large scale; Bonsai marks section drawings on the other drawings by itself.

1. Save the model. Set the **3D Cursor Location** to X `0`, Y `0`, Z `-0.4` (the centre line of C-A1 and F-A1).
2. In **Drawings and Documents > Drawings**, add a **Section** looking **North** (**+**, **Add Drawing**). Rename it `TYPICAL COLUMN FOOTING DETAIL` and activate it.
3. In **Active Drawing**, set **Width** `3`, **Height** `2.4`, **Depth** `1` and **Scale** 1:20. The frame shows F-A1 and the foot of C-A1 with their bars.
4. Pick the **Annotation Tool**, choose **Text** and click **Add** (Shift+A). A text appears near the cursor.
5. Press Shift+E (**Edit Text**). Replace the literal "TEXT" with `TYPICAL COLUMN FOOTING DETAIL` and click OK. Move the text above the footing with G.
6. Add four more texts the same way:
   - `CONCRETE C25/30`
   - `STEEL A500`
   - `BOTTOM MESH Ø16 @ 150 EACH WAY` (copy the Ø from this page if your keyboard has none)
   - `50 mm COVER`
7. If you want leaders, choose **Leader** in the Annotation Tool and add one per note; its text works the same way.
8. Click **Create Drawing**. Bonsai writes `drawings/TYPICAL COLUMN FOOTING DETAIL.svg`. Copy it as `detail.svg`.

## Check your work

Save or export your work as `detail.svg`, then run:

```
python -m bimcheck 5.3 detail.svg
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Details are where 2D annotation adds what the model does not show well. Keep notes short and tied to the model's data so they do not contradict it.
