# Exercise 4.3: Custom property set TB01_Structural

**Goal.** Add project-specific data with a custom property set (the open equivalent of shared parameters).

## What you build

- Property set **TB01_Structural** on every column, beam, slab and core wall.
- FireResistance: columns **R90**, beams **R60**, slab **REI60**, walls **REI90**.
- DesignWorkingLife: **50** on all of them.

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

1. Open `tb01.ifc` as in 4.1 (All individual IFC objects, Load the shape, Locked).
2. Select the 12 columns in the tree. Manage > Manage IFC Properties.
3. In **Add property set** choose **New** and type `TB01_Structural`. Check the spelling: the name is the contract.
4. With TB01_Structural selected, **Add property** > **Label**. Rename the new property `FireResistance` and set its value `R90`.
5. **Add property** > **Integer**. Rename it `DesignWorkingLife` and set `50`. Press OK. FreeCAD writes the property set into the IFC file and shows it as a property group TB01_Structural in the Data tab.
6. Repeat for the 17 beams (`R60`), the slab S-L1 (`REI60`) and the four core walls (`REI90`), each with DesignWorkingLife `50`.
7. Click one beam and check the TB01_Structural group in the property editor.
8. File > Save IFC File (Ctrl+S).

## In Bonsai

1. Deselect all (Alt+A). In **Project Overview > Grouping and Filtering > Search**, set the filter query (funnel icon) to `IfcColumn` and click **Search**.
2. Go to **Object Information > Misc > Bulk Property Editor > Bulk Add / Edit Custom Properties**. Click **Add Property to Edit** twice and fill in the rows:
   - `TB01_Structural`, `FireResistance`, `R90`, IfcLabel
   - `TB01_Structural`, `DesignWorkingLife`, `50`, IfcInteger
3. Click **Apply Changes**. Bonsai reports "12 elements changed".
4. Deselect all, search `IfcBeam`, change FireResistance to `R60` and click **Apply Changes**.
5. Do the same for `IfcSlab` (`REI60`) and `IfcWall` (`REI90`). DesignWorkingLife stays 50.
6. Check one element of each class in **Object Information > Object > Property Sets**: TB01_Structural with both properties. The name must be exactly `TB01_Structural`.
7. Save with **File > Save IFC Project**.

## Check your work

Save or export your work as `tb01.ifc`, then run:

```
python -m bimcheck 4.3 tb01.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Standard property sets (Pset_...) cover the common data; everything else a project needs goes into custom sets with an agreed name. The name is the contract: a typo means the data is invisible to whoever reads the model next.
