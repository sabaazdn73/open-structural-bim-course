# Exercise 4.1: Types for columns, beams and footings

**Goal.** Define element types and make every occurrence use one.

## What you build

- IfcColumnType **RC Column 400x400** used by all 12 columns.
- IfcBeamType **RC Beam 300x350 downstand** used by all 17 beams.
- IfcFootingType **Pad Footing 1800x1800x600** used by all 12 pad footings.

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

FreeCAD's IFC export (File > Export) writes no element types at all. Types exist in FreeCAD's native IFC mode, where FreeCAD edits the IFC file directly. From this exercise on you open `tb01.ifc` (exported at the end of 3.6) and work in it; keep `tb01.FCStd` as the source of sections 1 to 3.

1. File > Open…, choose `tb01.ifc`. In **IFC Import Options** set **Initial import** to **All individual IFC objects**, **Representation type** to **Load the shape (slower)** and **Lock document** to **Locked (IFC objects only)**. Press OK.
2. The File menu now shows **Save IFC File** and **Save IFC File As…**: in a locked IFC document Ctrl+S writes the IFC file itself.
3. In the tree, find column **C-A1** under Level 0. Right-click it and choose **Convert to Type**.
4. In **Convert to IFC Type**, tick **Keep original object. The object will adopt the new type** and press OK. A new IfcColumnType appears in the Types group of the tree.
5. Rename the new type (F2) `RC Column 400x400`. FreeCAD writes the label as the IFC name.
6. Select the other 11 columns. In the property editor (Data tab, group IFC) set **Type** to `RC Column 400x400`.
7. Do the same for beams: Convert to Type on **B-1/AB** (keep the original), rename the type `RC Beam 300x350 downstand`, set **Type** on the other 16 beams.
8. And for footings: Convert to Type on **F-A1**, rename it `Pad Footing 1800x1800x600`, set **Type** on F-A2 ... F-D3 (not on PC-1).
9. Convert to Type copies the element with all its relationships, so the new types are also in the groups of exercise 3.6. Take them out in View > Panels > Python Console:
   ```python
   f = FreeCAD.ActiveDocument.Proxy.ifcfile
   for rel in f.by_type("IfcRelAssignsToGroup"):
       rel.RelatedObjects = [o for o in rel.RelatedObjects if not o.is_a("IfcTypeObject")]
   FreeCAD.ActiveDocument.Modified = True
   ```
10. File > Save IFC File (Ctrl+S).

## In Bonsai

In Bonsai every column, beam and footing you placed with a tool already uses a type, so this exercise is a check and a tidy-up.

1. Select a column. **Object Information > Object > Type** shows **RC Column 400x400**.
2. Click the select icon next to the type name (**Select Similar Type**): Bonsai selects every occurrence of the type. All 12 columns light up.
3. Do the same for a beam (**RC Beam 300x350 downstand**, 17) and a pad footing (**Pad Footing 1800x1800x600**, 12). The pile cap has its own type and does not count here.
4. If an element has no type (for example a footing you made from a cube), select it, click the pencil in the **Type** panel (**Enable Editing Type**), choose the class and the type, and click the check mark (**Assign Type**).
5. To rename a type, open the tool's **Type Manager**, click the gear next to the type and choose **Rename Type**.
6. Try the point of types: in **Geometry and Materials > Profiles**, edit **RC 400x400** to 0.5 x 0.5. All 12 columns change at once. Set it back to 0.4 x 0.4.
7. Save with **File > Save IFC Project**.

## Check your work

Save or export your work as `tb01.ifc`, then run this from the course folder:

```
python -m bimcheck 4.1 tb01.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Types are IFC's version of Revit families and types: change the type once and every occurrence follows, and schedules can count by type. A model where every column is its own one-off object is hard to edit and hard to schedule.
