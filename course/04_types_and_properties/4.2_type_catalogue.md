# Exercise 4.2: Column type catalogue from a CSV file

**Goal.** Create column types from a catalogue file, the open equivalent of a Revit type catalogue.

## What you build

- Read `datasets/column_types.csv` (Name, Width_mm, Depth_mm).
- Create one IfcColumnType per row with that name. Store Width and Depth as type properties.
- Neither FreeCAD nor Bonsai has a button that imports types from a CSV file, so this exercise uses a short script, the way offices automate it.
- RC Column 400x400 is the type you made in 4.1: reuse it, do not duplicate it.

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

FreeCAD has no type-catalogue importer, so you load the catalogue with a short script. The IfcOpenShell library that ships with FreeCAD writes the types straight into the open IFC file.

1. Open `tb01.ifc` as in 4.1 (All individual IFC objects, Load the shape, Locked).
2. Open `datasets/column_types.csv` in a text editor and look at the three columns: Name, Width_mm, Depth_mm.
3. View > Panels > Python Console. Change the path to where your copy of the course is, and run:
   ```python
   import csv
   from nativeifc import ifc_tools
   f = FreeCAD.ActiveDocument.Proxy.ifcfile
   types = {t.Name: t for t in f.by_type("IfcColumnType")}
   for row in csv.DictReader(open("/path/to/course/datasets/column_types.csv", encoding="utf-8")):
       t = types.get(row["Name"]) or ifc_tools.api_run("root.create_entity", f, ifc_class="IfcColumnType", name=row["Name"])
       pset = ifc_tools.api_run("pset.add_pset", f, product=t, name="TB01_TypeData")
       ifc_tools.api_run("pset.edit_pset", f, pset=pset, properties={"Width": float(row["Width_mm"]), "Depth": float(row["Depth_mm"])})
   FreeCAD.ActiveDocument.Modified = True
   ```
4. The script reuses `RC Column 400x400` from 4.1 (it finds it by name) and creates the other types, each with Width and Depth in the property set TB01_TypeData.
5. Check: run `print([t.Name for t in f.by_type("IfcColumnType")])` in the console. Each catalogue name appears once.
6. File > Save IFC File (Ctrl+S).

If this does not work: if the console says `'NoneType' object has no attribute 'ifcfile'`, the active document is not the locked IFC document of step 1; click its 3D view and run the script again.

## In Bonsai

Bonsai can create types one by one in the Type Manager, but it cannot read a type catalogue from a CSV file. A short script does that. It reuses **RC Column 400x400** and adds the other rows as column types with a rectangular profile (as the Column Tool makes them), plus a property set **TB01_TypeData** with Width and Depth in metres.

1. Save your model (**File > Save IFC Project**).
2. Open the **Scripting** workspace. In the Text Editor click **New** and paste the script below.
3. Change the `CSV = ...` line to the full path of `datasets/column_types.csv` in your copy of the course.
4. Click **Run Script**. The system console prints "created RC Column 300x300", "reused RC Column 400x400", "created RC Column 500x500" and "created RC Column 300x600".
5. Save with **File > Save IFC Project**, then **File > Revert IFC Project** so Bonsai loads the new types.
6. Back in the BIM workspace, pick the **Column Tool** and open its **Type Manager**: you see the four types. Select a type (gear, **Select Type**) and look at **Object Information > Object > Property Sets** for Width and Depth.

```python
import csv
import ifcopenshell.api
import ifcopenshell.util.element
import ifcopenshell.util.unit
import bonsai.tool as tool

CSV = r"C:\path\to\open-structural-bim-course\datasets\column_types.csv"  # change to your copy

f = tool.Ifc.get()
run = ifcopenshell.api.run
scale = ifcopenshell.util.unit.calculate_unit_scale(f)  # project length unit -> metres
existing = {t.Name: t for t in f.by_type("IfcColumnType")}
concrete = next((m for m in f.by_type("IfcMaterial") if m.Name == "Concrete C30/37"), None)
concrete = concrete or run("material.add_material", f, name="Concrete C30/37", category="concrete")

with open(CSV, newline="", encoding="utf-8") as fh:
    for row in csv.DictReader(fh):
        w, d = float(row["Width_mm"]) / 1000 / scale, float(row["Depth_mm"]) / 1000 / scale
        t = existing.get(row["Name"])
        if t is None:  # new type with an extruded profile, as the Column Tool makes it
            t = run("root.create_entity", f, ifc_class="IfcColumnType", name=row["Name"], predefined_type="COLUMN")
            profile = f.create_entity("IfcRectangleProfileDef", ProfileName=f"RC {row['Width_mm']}x{row['Depth_mm']}",
                                      ProfileType="AREA", XDim=w, YDim=d)
            rel = run("material.assign_material", f, products=[t], type="IfcMaterialProfileSet")
            item = run("material.add_profile", f, profile_set=rel.RelatingMaterial, material=concrete)
            run("material.assign_profile", f, material_profile=item, profile=profile)
            print("created", row["Name"])
        else:
            print("reused", row["Name"])
        pset = ifcopenshell.util.element.get_pset(t, "TB01_TypeData")
        pset = f.by_id(pset["id"]) if pset else run("pset.add_pset", f, product=t, name="TB01_TypeData")
        run("pset.edit_pset", f, pset=pset, properties={"Width": f.createIfcPositiveLengthMeasure(w),
                                                          "Depth": f.createIfcPositiveLengthMeasure(d)})
```

If this does not work: "No such file or directory" means the CSV path is wrong. On Windows keep the `r` before the quotes.

## Why this matters

Offices keep their standard sections in catalogues so every project uses the same names and sizes. Loading types from a file is faster and less error-prone than typing them, and it is the kind of task you will automate with a script.
