# Exercise 2.5: Clean joints: no element counted twice

**Goal.** Check that no two elements overlap, and that the concrete volumes of the frame match the brief.

## What you build

- Fix any overlap between columns, beams, walls and the slab (for example a column running into the slab or a beam running into a column).
- Expected volumes: columns 6.43 m3, beams 10.84 m3, walls 9.21 m3, slab 63.06 m3; total 89.54 m3.

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## Check your work

Save or export your work as `tb01.ifc`, then run:

```
python -m bimcheck 2.5 tb01.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Revit handles this with 'join geometry' and structural connections. In open tools you get the same result by modelling each element to its true extent. Overlaps are not just untidy: they double count concrete in quantities and make clash reports noisy.
