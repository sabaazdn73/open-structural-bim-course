# Exercise 2.5: Clean joints: no element counted twice

**Goal.** Check that no two elements overlap, and that the concrete volumes of the frame match the brief.

## What you build

- Fix any overlap between columns, beams, walls and the slab (for example a column running into the slab or a beam running into a column).
- Expected volumes: columns 6.43 m3, beams 10.84 m3, walls 9.21 m3, slab 63.06 m3; total 89.54 m3.

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

In FreeCAD each element keeps the size you give it, so a clean frame comes from modelling every element to its true extent: columns and walls stop at +3.350, beams stop at the column faces, the slab sits on top.

1. Open `tb01.FCStd`. Select all 12 columns and check in the Data tab that **Height** reads `3350 mm` (it shows one value when all agree).
2. Select the four core walls: **Height** `3350 mm`, **Width** `250 mm`. The west and east walls run from y 9250 to 11750, between the south and north walls.
3. Select the beams along X: **Length** `5600 mm`; the beams along Y: **Length** `6600 mm`. A beam of 6000 or 7000 mm runs into the columns.
4. Select the slab: **Height** `250 mm`, base rectangle at z = 3600.
5. To see an overlap, select two elements and use Modify > Intersection. If the result has a volume, the two elements overlap; fix the size or position, then delete the intersection object.
6. Look at the volumes in Manage > Manage IFC Quantities: the **Volume** column shows each element. Expected totals: columns 6.43 m³, beams 10.84 m³, core walls 9.21 m³, slab 63.06 m³.
7. Close the dialog with Cancel (you add quantities in exercise 7.8). Save and export `tb01.ifc`.

## In Bonsai

Bonsai has no join command for concrete members. You get clean joints by modelling each element to its true extent, which you did in 2.1 to 2.4. This exercise checks it.

1. Hide the slab (H) and look at a column head: the beams stop at the column faces and the column stops at +3.350, under the slab.
2. In **Project Overview > Grouping and Filtering > Search**, click the funnel icon (**Edit Filter Query**), type `IfcColumn` and click OK, then click **Search**. Bonsai selects the 12 columns.
3. Go to **Costing and Scheduling > Quantity Take-off > Simple Quantity Calculator** and click **Calculate Object Volumes**. The result should be 6.43 m3.
4. Repeat for `IfcBeam` (10.84 m3), `IfcWall` (9.21 m3) and `IfcSlab` (63.06 m3). Deselect everything (Alt+A) before each search: **Search** adds to the selection.
5. If a total is too high, find the element that runs too far. Common causes: a column with height 3.6, a beam with length 6.0, a beam whose Location is on the grid instead of the column face.
6. Fix a column with its **H** value and **Update**, a beam with its **Length** and **Update**, or move it in the sidebar (N) > **Item**.
7. Unhide everything (Alt+H) and save with **File > Save IFC Project**.

## Check your work

Save or export your work as `tb01.ifc`, then run this from the course folder:

```
python -m bimcheck 2.5 tb01.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Revit handles this with 'join geometry' and structural connections. In open tools you get the same result by modelling each element to its true extent. Overlaps are not just untidy: they double count concrete in quantities and make clash reports noisy.
