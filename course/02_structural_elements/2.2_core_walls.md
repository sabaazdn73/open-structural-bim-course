# Exercise 2.2: Core walls traced from the architect's model

**Goal.** Link the architect's model and model the structural core walls exactly where the architect placed their load-bearing walls.

## What you build

- Open or link `datasets/architect_model.ifc` as a reference. It holds four load-bearing core walls (A-Core-1 to 4) and two partitions that are not yours to model.
- Model four 250 mm walls on the architect's core walls: outside faces x 7.5 to 10.5, y 9.0 to 12.0.
- From +0.000 to the slab soffit +3.350, in Level 0.
- Mark them load-bearing (`Pset_WallCommon.LoadBearing = True`).

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

1. Open `tb01.FCStd`. 3D/BIM > Generic 3D Tools > External Reference. In the property editor set **File** to `datasets/architect_model.ifc`. The architect's walls appear, read-only. Leave this object at the top of the tree, outside TB-01 Training Building, so it is not exported with your model.
2. In the top view, find the four core walls (x 7.5 to 10.5 m, y 9.0 to 12.0 m). The two partitions elsewhere are not yours.
3. Right-click **Level 0** and tick **Active**. Turn on Snapping > Snap Midpoint and Snap Endpoint.
4. 3D/BIM > Wall. In the task panel set **Width** `250 mm`, **Height** `3350 mm` and **Alignment** `Center`.
5. Trace the south wall along its centre line: click the midpoint of its west end, then the midpoint of its east end (7500, 9125 and 10500, 9125; you can also type the points in the X, Y, Z boxes and press Enter).
6. Trace the other three walls the same way, each with its own two clicks: north 7500, 11875 to 10500, 11875; west 7625, 9250 to 7625, 11750; east 10375, 9250 to 10375, 11750. The west and east walls stop at the inner faces of the south and north walls, so no two walls overlap.
7. Rename the walls `W-Core-S`, `W-Core-N`, `W-Core-W`, `W-Core-E`. For each, set **Predefined Type** (Data tab, group IFC Attributes) to `SOLIDWALL`; the default is MOVABLE.
8. Select the four walls. Manage > Manage IFC Properties. In **Add property set** pick **Wall Common** (Pset_WallCommon). Set **LoadBearing** to `True` and leave the other values empty (empty values are not exported). Press OK.
9. Select the External Reference and press Space to hide it. Clear **Active** on Level 0.
10. Save and export `tb01.ifc` with TB-01 Training Building selected.

If this does not work: if two walls become one object when you draw them, Edit > Preferences > BIM > General Settings has **Auto-join walls** ticked; clear it and draw again.

## In Bonsai

1. Go to **Project Overview > Project Setup > Links** and click **Link IFC**. Pick `datasets/architect_model.ifc`. The architect's walls appear in the viewport as a linked model you cannot edit.
2. Pick the **Explore Tool** in the toolbar and right-click a core wall of the link. The **Links** panel lists its attributes and properties (A-Core-1, LoadBearing True). The partitions are not yours.
3. Pick the **Wall Tool**. In the tool header click "No IfcWallTypes Found" and then **Create New IfcWallType**. Set **Name** `RC Wall 250`, **Predefined Type** SOLIDWALL, **Representation** Vertical Layers, and click OK.
4. Bonsai gives the new type one 0.1 m layer. In the **Type Manager**, click the gear next to RC Wall 250 and choose **Select Type**.
5. Go to **Geometry and Materials > Object Materials**. Click the pencil (**Enable Editing Assigned Material**), then the pencil on the layer (**Enable Editing Material Set Item**). Set **LayerThickness** `0.25` and **Material** Concrete C30/37, click **Save Changes**, then the check mark (**Edit Assigned Material**).
6. Make Level 0 the default container (**Spatial Decomposition > Set Default**). In the Wall Tool header set **RL** `0` and **H** `3.35`.
7. Click **Add** (Shift+A), click a start point and an end point anywhere, and press Enter. This draws one wall.
8. In the sidebar (N) > **Item**, set its **Location** and **Rotation Z**, then type the **Length** in the tool settings (sidebar **Tool** tab or header **L**) and click its refresh button (**Update**):

   | Wall | Location X, Y | Rotation Z | Length |
   |---|---|---|---|
   | W-Core-S | 7.5, 9.0 | 0 | 3.0 |
   | W-Core-N | 10.5, 12.0 | 180 | 3.0 |
   | W-Core-E | 10.5, 9.25 | 90 | 2.5 |
   | W-Core-W | 7.5, 11.75 | 270 | 2.5 |

   The layer lies on the left of the wall's direction, so each wall sits inside the core outline x 7.5 to 10.5, y 9.0 to 12.0. Location Z is 0.
9. Repeat steps 7 and 8 for the four walls and rename them in the Outliner.
10. Draw each wall on its own, so the long walls run through the corners and the short walls stop at them, as in the brief. If you draw the core as one closed outline, Bonsai mitres the corners: the volume is the same, but the overlap check in 2.5 compares bounding boxes and reports the corners.
11. Select the four walls. Go to **Object Information > Misc > Bulk Property Editor > Bulk Add / Edit Custom Properties** and click **Add Property to Edit**. Fill in `Pset_WallCommon`, `LoadBearing`, tick the value, data type **IfcBoolean**, and click **Apply Changes**.
12. Compare your walls with the link: in **Links**, set the link to wireframe with its cube icon. The faces should coincide.
13. Save with **File > Save IFC Project**.

## Check your work

Save or export your work as `tb01.ifc`, then run:

```
python -m bimcheck 2.2 tb01.ifc datasets/architect_model.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

On a real project you never type the architect's coordinates in again: you link their model and trace (or copy and monitor) the elements that are structural. Linking also shows you at once when the architect moves a wall. Partitions stay in the architect's model.
