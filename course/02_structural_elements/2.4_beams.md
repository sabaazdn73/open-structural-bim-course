# Exercise 2.4: Level 1 beams

**Goal.** Model the 17 downstand beams of Level 1.

## What you build

- One beam on every grid line between two columns: 9 along X (grids 1, 2, 3) and 8 along Y (grids A to D).
- 300 mm wide, 350 mm deep below the slab soffit (+3.000 to +3.350).
- Each beam stops at the column faces (clear spans: 5.6 m along X, 6.6 m along Y).
- Name them by grid line and bay: B-1/AB is the beam on grid 1 between A and B. Place them in Level 1.

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

FreeCAD places a beam on the line between the two points you give, with its section centred on that line. For a 350 mm downstand under the soffit (+3.000 to +3.350) the line is at mid-depth, z = 3175 mm.

1. Open `tb01.FCStd`. Right-click **Level 1** and tick **Active** (new beams go into Level 1).
2. 3D/BIM > Beam. In the task panel set **Width** `300 mm` and **Height** `350 mm`. Tick **Global** so the points you type are model coordinates, and tick **Continue**.
3. Beam B-1/AB on grid 1 between the faces of C-A1 and C-B1: type X `200`, Y `0`, Z `3175`, Enter; then X `5800`, Y `0`, Z `3175`, Enter.
4. Draw the other beams along X the same way: from x+200 to the next grid x-200, at y = 0, 7000 and 14000 (9 beams in total).
5. Beams along Y: from y+200 to the next grid y-200, at x = 0, 6000, 12000, 18000, for example B-A/12 from 0, 200, 3175 to 0, 6800, 3175 (8 beams).
6. Press Esc. Rename the beams `B-1/AB`, `B-1/BC`, `B-1/CD`, `B-2/AB` ... `B-D/23`: grid line, then the two grids of the bay.
7. Select one beam and check the Data tab: **Ifc Type** `Beam`, **Length** `5600 mm` (along X) or `6600 mm` (along Y), **Width** `300 mm`, **Height** `350 mm`.
8. Check that the 17 beams are inside Level 1. Clear **Active**, save and export `tb01.ifc`.

If this does not work: if a beam stands on end, you clicked instead of typing the second point at the same Z; delete it and type both points.

## In Bonsai

1. In **Geometry and Materials > Profiles**, add an **IfcRectangleProfileDef** named `RC 300x350` with **XDim** `0.30` (width) and **YDim** `0.35` (depth).
2. Pick the **Beam Tool** (click and hold the Column Tool button). Click "No IfcBeamTypes Found" and **Create New IfcBeamType**: **Name** `RC Beam 300x350 downstand`, **Predefined Type** BEAM, **Representation** Extruded Profile, **Profile** RC 300x350.
3. Make **Level 1** the default container. In the tool header set **Axis** to **top centre**, so the beam hangs from its top edge.
4. Click **Add** (Shift+A), click two points roughly along X and press Enter. Bonsai draws a beam from the first point to the second.
5. In the sidebar (N) > **Item**, set **Location** X `0.2`, Y `0`, Z `3.35`. In the tool settings type **Length** `5.6` and click its **Update** button. The beam now runs from the face of C-A1 to the face of C-B1, from +3.000 to +3.350.
6. Rename it `IfcBeam/B-1/AB` in the Outliner. Type the class prefix too: Bonsai keeps what comes after the first "/" as the IFC name, so `B-1/AB` alone would become "AB". You can also edit **Name** in **Object Attributes**.
7. Copy it: Shift+D, X, `6`, Enter, twice. Select the three beams and copy them Shift+D, Y, `7`, Enter, twice. You have the nine beams on grids 1, 2 and 3.
8. Draw one beam along Y the same way (two points roughly along Y). Set **Location** X `0`, Y `0.2`, Z `3.35` and **Length** `6.6`, **Update**. Name it `IfcBeam/B-A/12`.
9. Copy it Shift+D, X, `6`, Enter, three times. Select the four beams and copy them Shift+D, Y, `7`, Enter.
10. Rename all 17 beams: B-1/AB, B-1/BC, B-1/CD, B-2/..., B-3/... along X and B-A/12, B-A/23 ... B-D/23 along Y.
11. Check one beam in **Object Information > Object > Spatial Container**: Level 1. Save with **File > Save IFC Project**.

## Check your work

Save or export your work as `tb01.ifc`, then run:

```
python -m bimcheck 2.4 tb01.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

The full beam is 600 mm deep (350 downstand + 250 slab). Modelling only the downstand is a common convention that keeps the concrete volumes honest. Stopping beams at the column faces does the same at the joints.
