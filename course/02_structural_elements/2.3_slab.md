# Exercise 2.3: Level 1 slab with openings

**Goal.** Model the 250 mm Level 1 slab with the core and stair openings.

## What you build

- Top of slab +3.600, soffit +3.350.
- Edges at the outer column faces: x -0.2 to 18.2, y -0.2 to 14.2.
- Core opening x 7.75 to 10.25, y 9.25 to 11.75; stair opening x 13.0 to 14.2, y 1.0 to 6.4.
- Place the slab in Level 1. Expected volume: 63.06 m3.

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

1. Open `tb01.FCStd`. Right-click **Level 1** and tick **Active**. The working plane moves to Level 1 (+3.600), so what you draw now lies at the top of the slab.
2. 2D Drafting > Rectangle. Type the first corner `-200`, `-200` in the X and Y boxes and press Enter, then the opposite corner `18200`, `14200` and Enter. (If **Relative** is ticked in the task panel, type the size `18400`, `14400` instead.)
3. Select the rectangle and check the Data tab: **Length** `18400 mm`, **Height** `14400 mm`, **Placement > Position** -200, -200, 3600.
4. With the rectangle selected, 3D/BIM > Slab. FreeCAD extrudes it downwards. Set the slab's **Height** to `250 mm` (top +3.600, soffit +3.350) and rename it `S-L1`.
5. Make the core opening: 3D/BIM > Generic 3D Tools > Box, click three points anywhere and a height, then in the Data tab set **Length** `2500 mm`, **Width** `2500 mm`, **Height** `450 mm` and **Placement > Position** 7750, 9250, 3250. The box reaches 100 mm past the slab on both faces.
6. Make the stair opening the same way: Length `1200 mm`, Width `5400 mm`, Height `450 mm`, Position 13000, 1000, 3250.
7. Select the core box, then Ctrl+click the slab (the host is selected last). Modify > Remove Component. The box is hidden and cut out of the slab. Do the same with the stair box.
8. Check that S-L1 is inside Level 1 and that its **Subtractions** list (Data tab, group Component) holds the two boxes. FreeCAD exports them as IfcOpeningElement voids.
9. Clear **Active** on Level 1. Save and export `tb01.ifc`.

## In Bonsai

1. Pick the **Slab Tool** (it shares a toolbar button with Roof, Stair Flight and Ramp Flight: click and hold). Click "No IfcSlabTypes Found" and **Create New IfcSlabType**. Set **Name** `RC Slab 250`, **Predefined Type** FLOOR, **Representation** Horizontal Layers, and click OK.
2. Set the layer to 0.25 m before you draw, as in 2.2: **Type Manager**, gear, **Select Type**, then **Geometry and Materials > Object Materials**, edit the layer: **LayerThickness** `0.25`, **Material** Concrete C30/37, **Save Changes**, check mark.
3. Make **Level 1** the default container (**Spatial Decomposition > Set Default**).
4. Click **Add** (Shift+A). The status bar must say **Offset Type: TOP**, so the top of the slab is at Level 1 (+3.600) and its soffit at +3.350. Press O to change it if needed.
5. Type the four corners instead of clicking. For each corner press Tab until the **X** field is active, type the value, press Tab once for **Y**, type the value and press Enter:
   - X `-0.2`, Y `-0.2`
   - X `18.2`, Y `-0.2`
   - X `18.2`, Y `14.2`
   - X `-0.2`, Y `14.2`
6. Press Enter again to finish. Rename the slab `S-L1` in the Outliner.
7. Make the core opening: from the **Add** menu in the 3D viewport header choose **Mesh > Cube** and in the sidebar (N) > **Item** set **Location** `9.0`, `10.5`, `3.475` and **Dimensions** `2.5`, `2.5`, `0.45`. The cube passes right through the slab.
8. Make the stair opening the same way: **Location** `13.6`, `3.7`, `3.475`, **Dimensions** `1.2`, `5.4`, `0.45`.
9. Select one cube, then Shift-click the slab. With the Slab Tool active, click **Apply Void** in the tool settings (or press Shift+O). Bonsai turns the cube into an IfcOpeningElement that cuts the slab. Repeat for the other cube.
10. Check **Object Information > Object > Spatial Container**: the slab is in Level 1.
11. Select the slab and go to **Costing and Scheduling > Quantity Take-off > Simple Quantity Calculator**. Click **Calculate Object Volumes**: the result is 63.06 m3.
12. Save with **File > Save IFC Project**.

If this does not work: if the slab sits on top of Level 1 (+3.600 to +3.850), the offset was not TOP. Undo, check the status bar and draw it again.

## Check your work

Save or export your work as `tb01.ifc`, then run:

```
python -m bimcheck 2.3 tb01.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Openings must be real openings (voids) in the slab, not holes drawn on top of it, or the quantities and every downstream check will be wrong. The checker compares the slab's volume with the brief.
