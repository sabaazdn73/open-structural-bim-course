# Exercise 2.1: Columns

**Goal.** Place the twelve ground floor columns.

## What you build

- 400 x 400 mm columns at all 12 grid intersections.
- From Level 0 (+0.000) up to the underside of the Level 1 slab (+3.350), not to +3.600: the slab is modelled on its own and nothing is counted twice.
- Name each column by its grid position: C-A1, C-A2, ... C-D3.
- Place the columns in Level 0.

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

1. Open `tb01.FCStd`. In the tree, right-click **Level 0** and tick **Active**. New objects now go into Level 0.
2. Turn on Snapping > Snap Intersection (and leave the other snaps on).
3. 3D/BIM > Column. In the task panel set **Length** `400 mm`, **Width** `400 mm` and **Height** `3350 mm` (up to the slab soffit, not to +3.600). Tick **Continue** so the tool stays on.
4. Click the intersection of grids A and 1. The column is centred on the point you click. If the snap is hard to hit, type the point in the X, Y, Z boxes of the task panel and press Enter (A1 is 0, 0, 0).
5. Click the other 11 intersections: x = 0, 6000, 12000, 18000 for A to D and y = 0, 7000, 14000 for 1 to 3. Press Esc when done.
6. Rename every column by its grid position (select, F2): `C-A1`, `C-A2`, `C-A3`, `C-B1` ... `C-D3`. Use **Placement > Position** in the Data tab to see which one is which.
7. Select one column and check the Data tab: **Ifc Type** is `Column`, **Predefined Type** (group IFC Attributes) is `COLUMN`, **Height** is `3350 mm`.
8. Make sure the 12 columns are inside Level 0 in the tree; drag any that are not.
9. Right-click Level 0 and clear **Active**.
10. Save and export `tb01.ifc` (select TB-01 Training Building, File > Export…, Industry Foundation Classes).

## In Bonsai

Bonsai's element tools place occurrences of a type. You make the column type here; exercise 4.1 then only checks it.

1. Go to **Geometry and Materials > Materials**. Click the import icon (**Load Materials**), then **+** (**Add Material**). Name it `Concrete C30/37`, Category `concrete`, and click OK. New types take the first material in the file, so create this one before any type.
2. Go to **Geometry and Materials > Profiles** and click the import icon (**Load Profiles**). Choose **IfcRectangleProfileDef** in the dropdown and click **+** (**Add Profile**).
3. Double-click "New Profile" in the list and rename it `RC 400x400`. Click the pencil (**Enable Editing Profile**), set **XDim** `0.4` and **YDim** `0.4`, and click the check mark (**Edit Profile**).
4. In **Project Overview > Spatial > Spatial Decomposition**, click the **Level 0** row and click **Set Default**.
5. In the toolbar on the left of the 3D viewport, pick the **Column Tool**. The tool header says "No IfcColumnTypes Found". Click it to open the **Type Manager**, then click **Create New IfcColumnType**.
6. In the dialog set **Name** `RC Column 400x400`, **Predefined Type** COLUMN, **Representation** Extruded Profile, **Profile** RC 400x400, and click OK.
7. In the tool header set **Axis** to mid-depth centre and **H** (height) to `3.35`. The column runs from Level 0 up to the slab soffit, not to +3.600.
8. Click **Add** (Shift+A), click once anywhere in the viewport, then right-click to stop. Bonsai places one column on Level 0.
9. With the column selected, open the sidebar (N) > **Item** and set **Location** X `0`, Y `0`, Z `0`.
10. In the Outliner, double-click the column and rename it `C-A1`.
11. Copy it along grid 1: press Shift+D, X, type `6`, Enter. Repeat twice more for x = 12 and 18.
12. Select the four columns on grid 1. Press Shift+D, Y, `7`, Enter, then repeat once more for y = 14.
13. Rename every column in the Outliner by its grid: C-A1, C-B1 ... C-D3 (letter for x, number for y).
14. Check that **Object Information > Object > Spatial Container** says Level 0 for a column. Save with **File > Save IFC Project**.

If this does not work: if a column stands on the wrong level, check that Level 0 was the default container before you clicked Add, then set the Location Z to 0.

## Check your work

Save or export your work as `tb01.ifc`, then run this from the course folder:

```
python -m bimcheck 2.1 tb01.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Columns at grid intersections are the simplest structural element, but they teach the three habits every model needs: exact setting out from the grid, a clear top and bottom, and a mark that matches the drawings. Stopping the column at the slab soffit keeps the concrete quantities right (exercise 2.5).
