# Exercise 1.3: Structural grid

**Goal.** Draw the structural grid that every element will be set out from.

## What you build

- Lettered axes A, B, C, D parallel to Y at x = 0, 6, 12, 18 m.
- Numbered axes 1, 2, 3 parallel to X at y = 0, 7, 14 m.
- Each axis must run across the whole building (A to D lines from below grid 1 to beyond grid 3, and so on). Grid lines extend 2 m past the outer grids (see the brief).

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

Setup Project (exercise 1.1) made two axis objects, **Vertical Axes** and **Horizontal Axes**, joined in the axis system **Axes** inside the group Building Layout. FreeCAD exports an axis system with two sets of axes as one IfcGrid. Here you give them the TB-01 tags, lengths and positions.

1. Open `tb01.FCStd` and switch to the top view: View > Standard Views > 2 Top.
2. Select **Vertical Axes**. Check in the Data tab that **Distances** reads 0, 6000, 6000, 6000 (axes at x = 0, 6, 12, 18 m).
3. In the View tab set **Numbering Style** to `A,B,C`. These are the lettered axes A to D, parallel to Y.
4. In the Data tab set **Length** to `18000 mm` (14 m between grids 1 and 3, plus 2 m at each end) and **Placement > Position > y** to `-2000 mm`.
5. Rename the object `Grid A-D` (F2).
6. Select **Horizontal Axes**. Check that **Distances** reads 0, 7000, 7000 and that **Placement > Angle** is 90 °.
7. In the View tab set **Numbering Style** to `1,2,3`.
8. In the Data tab set **Length** to `22000 mm` and **Placement > Position > x** to `20000 mm`. Turned 90 °, these axes run from x = +20 m back to x = -2 m, at y = 0, 7 and 14 m.
9. Rename the object `Grid 1-3`.
10. Check the drawing: bubbles A to D at the bottom and top, 1 to 3 at both ends, every line 2 m past the outer grids.
11. Save and export `tb01.ifc` as before.

If this does not work: axes made one by one with Annotation > Axis are exported as loose IfcGridAxis items without an IfcGrid. Select both axis objects and use Annotation > Axis System to join them.

## In Bonsai

Bonsai's **Add Grids** button makes a rectangular grid: lettered U axes run along X and numbered V axes ("01", "02"...) run along Y. The brief wants the opposite, so you set the spacings and then swap the labels.

1. Go to **Project Overview > Spatial > Grids** and click **Add Grids**.
2. Move the mouse over the 3D viewport and choose **Edit > Adjust Last Operation** (F9). Set **U Spacing** `7`, **Number of U Grids** `3`, **V Spacing** `6`, **Number of V Grids** `4`.
3. You now have horizontal axes A, B, C at y = 0, 7, 14 and vertical axes 01 to 04 at x = 0, 6, 12, 18. Every axis runs 2 m past the outer axes.
4. In the Outliner, double-click **IfcGridAxis/A** and type `1`. Bonsai writes the new name into the axis tag. Rename **B** to `2` and **C** to `3`.
5. Now rename the vertical axes: **01** to `A`, **02** to `B`, **03** to `C`, **04** to `D`. Rename the horizontal ones first, as in step 4, or Blender adds ".001" to a duplicate name.
6. Check in the 3D viewport that A to D run along Y and 1 to 3 run along X.
7. Save with **File > Save IFC Project**.

If this does not work (for example the Adjust Last Operation panel does not appear): delete the grid in the Outliner (select it, X, **IFC Delete**). Open the **Scripting** workspace, click **New** in the Text Editor, paste the script below and click **Run Script**. Then save with **File > Save IFC Project** and reload with **File > Revert IFC Project** so the axes appear in the viewport.

```python
import numpy as np
import ifcopenshell.api
import bonsai.tool as tool

f = tool.Ifc.get()
run = ifcopenshell.api.run
level0 = [s for s in f.by_type("IfcBuildingStorey") if s.Name == "Level 0"][0]
grid = run("root.create_entity", f, ifc_class="IfcGrid", name="Structural Grid")
run("geometry.edit_object_placement", f, product=grid)
run("spatial.assign_container", f, relating_structure=level0, products=[grid])
for tag, x in {"A": 0.0, "B": 6.0, "C": 12.0, "D": 18.0}.items():   # parallel to Y, 2 m past grids 1 and 3
    axis = run("grid.create_grid_axis", f, axis_tag=tag, uvw_axes="UAxes", grid=grid)
    run("grid.create_axis_curve", f, p1=np.array([x, -2.0, 0.0]), p2=np.array([x, 16.0, 0.0]), grid_axis=axis)
for tag, y in {"1": 0.0, "2": 7.0, "3": 14.0}.items():              # parallel to X, 2 m past grids A and D
    axis = run("grid.create_grid_axis", f, axis_tag=tag, uvw_axes="VAxes", grid=grid)
    run("grid.create_axis_curve", f, p1=np.array([-2.0, y, 0.0]), p2=np.array([20.0, y, 0.0]), grid_axis=axis)
print("Grid axes:", [a.AxisTag for a in f.by_type("IfcGridAxis")])
```

## Why this matters

The grid is the contract between all disciplines: drawings, site setting out and coordination meetings all refer to 'B/2', not to coordinates. In IFC it is an *IfcGrid* with *IfcGridAxis* objects, each with a tag (A, 1...) that other programs can read.
