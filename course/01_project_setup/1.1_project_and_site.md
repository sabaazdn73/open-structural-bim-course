# Exercise 1.1: Project, site, building, units and location

**Goal.** Start the TB-01 model: name the project, the site and the building, use metric units, and place the site on the map with its true north.

## What you build

- Project name **TB-01 Training Building**, site **TB-01 Site**, building **TB-01**.
- Units: metres (or millimetres).
- Site latitude **38.7369**, longitude **-9.1427**, elevation of Level 0 **90.0 m** above sea level.
- True north **12 degrees clockwise** from project north (the +Y axis of the model).

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## Check your work

Save or export your work as `tb01.ifc`, then run:

```
python -m bimcheck 1.1 tb01.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Every other model on the project (architecture, MEP, survey) must land in the same place. Names, units and location are the first thing a coordinator checks when two models do not line up, and the first thing a permit portal reads. Project north is the drawing's 'up'; true north is the real one, and the angle between them drives orientation, sun studies and the setting out on site.
