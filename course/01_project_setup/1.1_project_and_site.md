# Exercise 1.1: Project, site, building, units and location

**Goal.** Start the TB-01 model: name the project, the site and the building, use metric units, and place the site on the map with its true north.

## What you build

- Project name **TB-01 Training Building**, site **TB-01 Site**, building **TB-01**.
- Units: metres (or millimetres).
- Site latitude **38.7369**, longitude **-9.1427**, elevation of Level 0 **90.0 m** above sea level.
- True north **12 degrees clockwise** from project north (the +Y axis of the model).

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

In FreeCAD you build TB-01 as a normal FreeCAD document (`tb01.FCStd`) with the BIM workbench, and export it to IFC at the end of every exercise. From section 4 on you open that IFC file and edit it directly.

1. Start FreeCAD 1.1 and switch to the BIM workbench: View > Workbench > BIM.
2. Manage > BIM Setup. Set **Preferred working units** to **Millimeters** and press OK. FreeCAD always writes IFC files in metres, so millimetres here are only for typing.
3. Manage > Setup Project. Tick **Create a New BIM Project**, choose **Create a new document without IFC support** and type the **Project name** `TB-01 Training Building`.
4. Tick **Create Site**. Name `TB-01 Site`, Latitude `38.7369`, Longitude `-9.1427`, Elevation `90 m`. Leave Declination at 0; you set it in step 9.
5. Tick **Create Building**. Name `TB-01`. Number of V axes `4`, Distance between V axes `6000 mm`, Number of H axes `3`, Distance between H axes `7000 mm`. You finish these axes in exercise 1.3.
6. In **Levels** set Number of levels `4` and Level height `3600 mm`. You finish the levels in exercise 1.2.
7. Clear **Add Human Figure** and press **OK**. The tree now shows TB-01 Site > TB-01 > Building Layout, Level 0 ... Level 3.
8. Select **TB-01 Site** in the tree. In the property editor (Data tab, group Site) check Latitude, Longitude and Elevation (90000 mm).
9. Still on the site, set **Declination** to `-12 °`. FreeCAD counts this angle counter-clockwise, so -12 ° puts true north 12 degrees clockwise from project north.
10. Name the IFC project. FreeCAD 1.1 has no button for the classic project object, so open View > Panels > Python Console and run:
    ```python
    import Arch
    Arch.makeProject([FreeCAD.ActiveDocument.getObjectsByLabel("TB-01 Site")[0]], name="TB-01 Training Building")
    ```
    A **TB-01 Training Building** object appears at the top of the tree, with the site inside it.
11. File > Save As…, `tb01.FCStd`.
12. Select **TB-01 Training Building** in the tree. File > Export…, set the file type to **Industry Foundation Classes (*.ifc)** and save as `tb01.ifc`. Export this way, with the project selected, at the end of every exercise up to 3.6.

If this does not work: if the checker reports the project name as `Unnamed`, step 10 was skipped; without the project object FreeCAD names the IfcProject after the internal document name.

## In Bonsai

Bonsai works in IFC directly: the file you save is `tb01.ifc`. The panels below are in the Properties editor on the right of the screen. Pick a Bonsai tab with the icons at the top of that editor (Project Overview, Object Information, Geometry and Materials, Drawings and Documents, Costing and Scheduling, Quality and Coordination). The sidebar of the 3D viewport opens with N.

1. Start Blender with Bonsai enabled. Choose **File > New IFC Project > New Metric (m) Project**. Bonsai creates an IFC4 project in metres with My Project, My Site, My Building and My Storey.
2. In the Outliner, click **IfcProject/My Project**. In **Object Information > Object > Object Attributes**, click **Edit**, set **Name** to `TB-01 Training Building` and click **Save Attributes**.
3. Do the same for **IfcSite/My Site** (Name `TB-01 Site`) and **IfcBuilding/My Building** (Name `TB-01`).
4. Select the site again and click **Edit** in **Object Attributes**. Type the location as degrees, minutes, seconds and millionths of a second, in square brackets:
   - **RefLatitude** `[38, 44, 12, 840000]` (38.7369)
   - **RefLongitude** `[-9, -8, -33, -720000]` (-9.1427, every part negative)
   - **RefElevation** `90`
5. Click **Save Attributes**.
6. Open **Project Overview > Geometry > Georeferencing** and expand its **True North** subpanel. It says "No True North Found". Click the pencil (**Enable Editing True North**).
7. Type `-12` in **Angle**. Bonsai counts angles anticlockwise, so -12 means 12 degrees clockwise. **Abscissa** becomes 0.2079 and **Ordinate** 0.9781. Click **Edit True North**.
8. Check **Project Overview > Geometry > Units**: the length unit is the metre.
9. Choose **File > Save IFC Project** (Ctrl+S) and save as `tb01.ifc` in your course folder. **File > Save** saves only the Blender file, not the IFC.

If this does not work: the site fields only accept whole numbers in the list. Check that you typed four integers, separated by commas, inside square brackets.

## Check your work

Save or export your work as `tb01.ifc`, then run this from the course folder:

```
python -m bimcheck 1.1 tb01.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Every other model on the project (architecture, MEP, survey) must land in the same place. Names, units and location are the first thing a coordinator checks when two models do not line up. Project north is the drawing's 'up'; true north is the real one, and the angle between them drives orientation, sun studies and the setting out on site.
