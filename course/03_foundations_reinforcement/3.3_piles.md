# Exercise 3.3: Pile cap and piles under the core

**Goal.** Support the core on a pile cap and four piles.

## What you build

- Pile cap PC-1: 4.0 x 4.0 x 1.0 m centred at x 9.0, y 10.5, top -0.600; footing type PILE_CAP (on the cap or on its type).
- Four piles (IfcPile), 600 mm diameter, 12 m long, at 1.2 m each way from the core centre, from the underside of the cap (-1.600) down to -13.600.
- Everything in the Foundation level.

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

1. Open `tb01.FCStd`. Right-click **Foundation** and tick **Active**.
2. Pile cap: 3D/BIM > Column with **Length** `4000 mm`, **Width** `4000 mm`, **Height** `1000 mm`. Tick **Global** and type the point 9000, 10500, -1600, Enter.
3. Rename it `PC-1`. In the Data tab set **Ifc Type** `Footing`, then **Predefined Type** `PILE_CAP`.
4. Piles: switch to View > Workbench > Part and use Part > Primitives > Cylinder. Set **Radius** `300 mm`, **Height** `12000 mm` and **Placement > Position** 7800, 9300, -13600.
5. Make three more cylinders the same way (or Edit > Duplicate Selection and change the position): 10200, 9300; 7800, 11700; 10200, 11700, all at z -13600. The tops are at -1.600, the underside of the cap.
6. Switch back to the BIM workbench. Select the four cylinders and use 3D/BIM > Column. FreeCAD makes one structure from each cylinder.
7. Rename them `P-1` to `P-4`. Select all four and set **Ifc Type** `Pile` and **Predefined Type** `BORED`.
8. Check that PC-1 and the four piles are inside the Foundation level. Clear **Active**, save and export `tb01.ifc`.

If this does not work: do not make the piles from a Draft circle. In FreeCAD 1.1.3 the IFC export of a circle-based structure with Ifc Type Pile stops with "Cannot create polygon because less than two vertices are given". Piles made from a Part cylinder export as faceted solids, about 2 % smaller in volume than a true cylinder.

## In Bonsai

1. In **Geometry and Materials > Profiles**, add an **IfcRectangleProfileDef** `RC 4000x1000` (**XDim** `4.0`, **YDim** `1.0`) and an **IfcCircleProfileDef** `Pile 600` (**Radius** `0.3`).
2. With the **Footing Tool**, open the **Type Manager** and click **Create New IfcFootingType**: **Name** `Pile Cap 4000x4000x1000`, **Predefined Type** PILE_CAP, **Representation** Extruded Profile, **Profile** RC 4000x1000.
3. Keep **Foundation** as the default container and **Axis** bottom centre. Pick the new type in the tool header.
4. Click **Add**, click two points roughly along X and press Enter. Set **Location** `7.0`, `10.5`, `-1.6` and **Length** `4.0`, **Update**. The cap spans x 7.0 to 11.0, y 8.5 to 12.5, from -1.600 to -0.600. Name it `PC-1`.
5. Pick the **Pile Tool**. Click "No IfcPileTypes Found" and **Create New IfcPileType**: **Name** `Bored Pile 600`, **Predefined Type** BORED, **Representation** Extruded Profile, **Profile** Pile 600.
6. Piles extrude upwards like columns. In the tool header set **Axis** mid-depth centre and **H** `12`.
7. Click **Add**, click once in the viewport and right-click to stop. Set **Location** `7.8`, `9.3`, `-13.6`: the pile runs from -13.600 up to the underside of the cap at -1.600. Name it `P-1`.
8. Copy it Shift+D, X, `2.4`, Enter (P-2 at x 10.2). Select both and copy them Shift+D, Y, `2.4`, Enter (P-3, P-4 at y 11.7).
9. Check that the cap and the four piles are in **Foundation** (**Spatial Container**). Save with **File > Save IFC Project**.

## Check your work

Save or export your work as `tb01.ifc`, then run:

```
python -m bimcheck 3.3 tb01.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Piles and caps show how IFC separates element classes (IfcPile, IfcFooting) and predefined types (PILE_CAP, PAD_FOOTING). Getting the class right is what lets a contractor's software pick up the piles for the piling subcontract.
