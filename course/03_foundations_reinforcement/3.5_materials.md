# Exercise 3.5: Materials and concrete data

**Goal.** Give every element its material and its concrete data.

## What you build

- Columns, beams, slab and core walls: material **Concrete C30/37**.
- Pad footings, the pile cap and the piles: **Concrete C25/30**.
- On every concrete element, `Pset_ConcreteElementGeneral`: StrengthClass (C30/37 or C25/30) and ExposureClass (XC1 inside the building, XC2 for footings, cap and piles).

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

1. Open `tb01.FCStd`. Select the 12 columns, 17 beams, 4 core walls, the slab S-L1 and the stair ST-1 (Ctrl+click in the tree).
2. Manage > Material. Press **New Material**, set **Name** `Concrete C30/37` and press OK. Back in the list, pick Concrete C30/37 and press OK: the selected elements get it (Data tab, group Component, **Material**).
3. Select the 12 pad footings, PC-1 and the four piles. Manage > Material, **New Material** `Concrete C25/30`, then assign it the same way.
4. Check that the six rebar objects have **A500** (exercise 3.4).
5. Select the elements of step 1. Manage > Manage IFC Properties. In **Add property set** choose **New** and type `Pset_ConcreteElementGeneral`. Do not pick the preset called Concrete Element Genera: FreeCAD 1.1.3 lists it with a typing error and the checker would not find it.
6. With the new property set selected, use **Add property** and pick **Label**. Rename the new property `StrengthClass` and give it the value `C30/37`. Add a second **Label** property `ExposureClass` with the value `XC1`. Press OK.
7. Select the footings, PC-1 and the piles and do the same with `C25/30` and `XC2`.
8. Save and export `tb01.ifc`. Each concrete element now has an IfcMaterial and Pset_ConcreteElementGeneral.

## In Bonsai

1. Columns, beams, the slab and the walls already have **Concrete C30/37**: their types took the first material in the file (2.1). Check one: **Geometry and Materials > Object Materials** shows it as the inherited material.
2. In **Geometry and Materials > Materials**, click **+** (**Add Material**) and add `Concrete C25/30`, Category `concrete`.
3. Select one pad footing. In **Object Materials**, click the pencil (**Enable Editing Assigned Material**), then the pencil on the profile item (**Enable Editing Material Set Item**). Choose **Material** Concrete C25/30, click **Save Changes**, then the check mark. The profile set belongs to the type, so all 12 footings change.
4. Do the same with the pile cap and with one pile.
5. Give the stair a material too: select it, choose IfcMaterial and Concrete C30/37 in **Object Materials** and click **+** (**Assign Material**).
6. Deselect all (Alt+A). In **Project Overview > Grouping and Filtering > Search**, click the funnel (**Edit Filter Query**), type `IfcColumn, IfcBeam, IfcSlab, IfcWall` and click **Search**.
7. Go to **Object Information > Misc > Bulk Property Editor > Bulk Add / Edit Custom Properties**. Click **Add Property to Edit** twice and fill in:
   - `Pset_ConcreteElementGeneral`, `StrengthClass`, `C30/37`, IfcLabel
   - `Pset_ConcreteElementGeneral`, `ExposureClass`, `XC1`, IfcLabel
8. Click **Apply Changes**. Bonsai reports how many elements changed.
9. Deselect all, search `IfcFooting, IfcPile`, change the values to `C25/30` and `XC2` and click **Apply Changes** again.
10. Check one footing in **Object Information > Object > Property Sets**. Save with **File > Save IFC Project**.

## Check your work

Save or export your work as `tb01.ifc`, then run this from the course folder:

```
python -m bimcheck 3.5 tb01.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

The material drives the quantities by concrete class and the colours in views; the property set is what a reviewer or an automatic check reads. A model without this data looks finished but cannot be checked.
