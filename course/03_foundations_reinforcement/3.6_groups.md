# Exercise 3.6: Selection groups

**Goal.** Save two selection groups you will reuse.

## What you build

- Group **Ground Floor Columns** with exactly the 12 columns.
- Group **Level 1 Beams** with exactly the 17 beams.

All numbers come from the [project brief](../../brief/README.md) and its [drawings](../../brief/drawings/).

## In FreeCAD

In FreeCAD a selection group is a plain group inside a level. An object can be in only one group, so the group goes inside the level and the elements move into it; FreeCAD still writes them as contained in the level.

1. Open `tb01.FCStd`. Right-click **Level 0** in the tree and choose **New Group**. Rename the group `Ground Floor Columns`.
2. Select the 12 columns C-A1 ... C-D3 in the tree and drag them onto Ground Floor Columns.
3. Right-click **Level 1** > **New Group**, rename it `Level 1 Beams` and drag the 17 beams into it.
4. Edit > Preferences > Import-Export > IFC Export. Tick **Export FreeCAD Groups** and clear **Export nested groups as assemblies**. Without the first box FreeCAD drops groups; with the second it writes groups inside levels as element assemblies, not IfcGroup.
5. Press OK. Save and export `tb01.ifc` (TB-01 Training Building selected).
6. Keep these two settings for the rest of the course.

## In Bonsai

1. Deselect all (Alt+A). In **Project Overview > Grouping and Filtering > Search**, set the filter query (funnel icon) to `IfcColumn` and click **Search**: the 12 columns are selected.
2. Open **Project Overview > Grouping and Filtering > Groups** and click the pencil (**Load Groups**).
3. Click **+** (**Add New Group**). A group named "Unnamed" appears in the list.
4. With the group active, click its pencil (**Enable Editing Group**), set **Name** `Ground Floor Columns` and click **Save Group**.
5. With the columns still selected, click the arrow icon (**Assign Group**). The group now holds the 12 columns.
6. Deselect all, search `IfcBeam` (17 beams), add a second group named `Level 1 Beams` and assign the beams the same way.
7. Test them: deselect all and click the select icon (**Select Group elements**) of each group.
8. Save with **File > Save IFC Project**.

## Check your work

Save or export your work as `tb01.ifc`, then run this from the course folder:

```
python -m bimcheck 3.6 tb01.ifc
```

Every line should say PASS. A FAIL line tells you what was expected and what was found.

## Why this matters

Groups (IfcGroup) are saved selections that travel with the model: another engineer can open the IFC and select the same set. They are the open equivalent of Revit's selection sets.
