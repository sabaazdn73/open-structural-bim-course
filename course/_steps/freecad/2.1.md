1. Open `tb01.FCStd`. In the tree, right-click **Level 0** and tick **Active**. New objects now go into Level 0.
2. Turn on Snapping > Snap Intersection (and leave the other snaps on).
3. 3D/BIM > Column. In the task panel set **Length** `400 mm`, **Width** `400 mm` and **Height** `3350 mm` (up to the slab soffit, not to +3.600). Tick **Continue** so the tool stays on.
4. Click the intersection of grids A and 1. The column is centred on the point you click. If the snap is hard to hit, type the point in the X, Y, Z boxes of the task panel and press Enter (A1 is 0, 0, 0).
5. Click the other 11 intersections: x = 0, 6000, 12000, 18000 for A to D and y = 0, 7000, 14000 for 1 to 3. Press Esc when done.
6. Rename every column by its grid position (select, F2): `C-A1`, `C-A2`, `C-A3`, `C-B1` ... `C-D3`. Use **Placement > Position** in the Data tab to see which one is which.
7. Select one column and check the Data tab: **Ifc Type** is `Column`, **Predefined Type** (group IFC Attributes) is `COLUMN`, **Height** is `3350 mm`.
8. Make sure the 12 columns are inside Level 0 in the tree; drag any that are not.
9. Right-click Level 0 and clear **Active**.
10. Save and export `tb01.ifc` (select TB-01 Training Building, File > Export…, Industry Foundation Classes).
