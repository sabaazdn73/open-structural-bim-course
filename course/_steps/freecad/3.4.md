FreeCAD's own tool is 3D/BIM > Custom Rebar: you draw the centre line of one bar, select it with its host, and the rebar object repeats that bar along a direction. (The Reinforcement add-on, installed with Tools > Addon Manager, adds a 3D/BIM > Reinforcement Tools menu with Column Reinforcement and Footing Reinforcement; this course uses Custom Rebar, which needs no add-on.) C-A1 is at 0, 0 and F-A1 under it, so the coordinates below are simple.

1. Open `tb01.FCStd`. Bar centres in C-A1 are 154 mm from the column axis (200 - 30 cover - 8 link - 8 half bar).
2. 2D Drafting > Line with **Global** ticked: from -154, -154, 0 to -154, -154, 3350 (the first vertical bar of the south face).
3. Select **C-A1**, then Ctrl+click the line. 3D/BIM > Custom Rebar.
4. In the Data tab of the new rebar set **Diameter** `16 mm`, **Amount** `3`, **Direction** 1, 0, 0, **Distance** `308 mm`, **Offset Start** and **Offset End** `0 mm`. Three bars appear at x -154, 0, +154. Set **Predefined Type** to `MAIN` and rename it `C-A1 vertical south`.
5. Repeat for the north face (line from -154, 154, 0 to -154, 154, 3350, Amount 3) and the two mid-side bars (line from -154, 0, 0 to -154, 0, 3350, Amount 2, Distance 308 mm). That makes 8 bars.
6. Links: 2D Drafting > Rectangle with corners -166, -166, 50 and 166, 166, 50 (the centre line of an 8 mm link at 30 mm cover). In its Data tab check **Length** and **Height** `332 mm` and **Placement > Position** -166, -166, 50, and set **Make Face** to `false`.
7. Select C-A1, Ctrl+click the rectangle, 3D/BIM > Custom Rebar. Set **Diameter** `8 mm`, **Amount** `22`, **Direction** 0, 0, 1, **Distance** `3150 mm`, offsets `0`, **Rounding** `2`, **Predefined Type** `LIGATURE`.
8. Footing mesh, bottom layer along X: line from -850, -842, -1142 to 850, -842, -1142. Select F-A1 and the line, Custom Rebar: **Diameter** `16 mm`, **Amount** `12`, **Direction** 0, 1, 0, **Distance** `1650 mm`, offsets `0`.
9. Second layer along Y, on top of the first: line from -842, -850, -1126 to -842, 850, -1126, Custom Rebar with **Direction** 1, 0, 0, the rest as in step 8.
10. Select the six rebar objects, Manage > Material, press **New Material**, name it `A500` and press OK, then pick A500 in the list to give it to the bars.
11. Drag the four column rebars into Level 0 and the two mesh rebars into Foundation. Save and export `tb01.ifc`.

If this does not work: the same bars from the Python console (View > Panels > Python Console), with C-A1 and F-A1 already in the model:
```python
import Arch, Draft
from FreeCAD import Vector as V
doc = FreeCAD.ActiveDocument
col, ft = doc.getObjectsByLabel("C-A1")[0], doc.getObjectsByLabel("F-A1")[0]
steel = Arch.makeMaterial(name="A500")
def bar(host, base, d, n, direction, dist, kind="MAIN"):
    r = Arch.makeRebar(host, base, diameter=d, amount=n, offset=0)
    r.Direction, r.Distance, r.PredefinedType, r.Material = V(*direction), dist, kind, steel
    return r
o = 154  # 200 - 30 cover - 8 link - 8 (half a bar)
for y, n in ((-o, 3), (o, 3), (0, 2)):
    bar(col, Draft.make_wire([V(-o, y, 0), V(-o, y, 3350)]), 16, n, (1, 0, 0), 2 * o)
link = Draft.make_rectangle(332, 332, placement=FreeCAD.Placement(V(-166, -166, 50), FreeCAD.Rotation()), face=False)
bar(col, link, 8, 22, (0, 0, 1), 21 * 150, "LIGATURE").Rounding = 2
bar(ft, Draft.make_wire([V(-850, -842, -1142), V(850, -842, -1142)]), 16, 12, (0, 1, 0), 1650)
bar(ft, Draft.make_wire([V(-842, -850, -1126), V(-842, 850, -1126)]), 16, 12, (1, 0, 0), 1650)
doc.recompute()
```
