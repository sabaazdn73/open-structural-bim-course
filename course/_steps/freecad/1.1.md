In FreeCAD you build TB-01 as a normal FreeCAD document (`tb01.FCStd`) with the BIM workbench, and export it to IFC at the end of every exercise. From section 4 on you open that IFC file and edit it directly.

1. Start FreeCAD 1.1 and switch to the BIM workbench: View > Workbench > BIM.
2. Manage > BIM Setup. Set **Preferred working units** to **Millimeters** and press OK. FreeCAD always writes IFC files in metres, so millimetres here are only for typing.
3. Manage > Setup Project. Tick **Create a New BIM Project**, choose **Create a new document without IFC support** and type the **Project name** `TB-01 Training Building`.
4. Tick **Create Site**. Name `TB-01 Site`, Latitude `38.7369`, Longitude `-9.1427`, Elevation `90 m`. Leave Declination at 0; you set it in step 9.
5. Tick **Create Building**. Name `TB-01`. Number of V axes `4`, Distance between V axes `6000 mm`, Number of H axes `3`, Distance between H axes `7000 mm`. You finish these axes in exercise 1.3.
6. In **Levels** set Number of levels `4` and Level height `3600 mm`. You finish the levels in exercise 1.2.
7. Clear **Add Human Figure** and press **OK**. The tree now shows TB-01 Site > TB-01 > Building Layout, Level 0 ... Level 3.
8. Select **TB-01 Site** in the tree. In the property editor (Data tab, group Site) check Latitude, Longitude and Elevation (90000 mm).
9. Still on the site, set **Declination** to `-12 °`. FreeCAD counts this angle counter-clockwise, so -12 ° puts true north 12 degrees clockwise from project north.
10. Name the IFC project. FreeCAD 1.1 has no button for the classic project object, so open View > Panels > Python Console and run:
    ```python
    import Arch
    Arch.makeProject([FreeCAD.ActiveDocument.getObjectsByLabel("TB-01 Site")[0]], name="TB-01 Training Building")
    ```
    A **TB-01 Training Building** object appears at the top of the tree, with the site inside it.
11. File > Save As…, `tb01.FCStd`.
12. Select **TB-01 Training Building** in the tree. File > Export…, set the file type to **Industry Foundation Classes (*.ifc)** and save as `tb01.ifc`. Export this way, with the project selected, at the end of every exercise up to 3.6.

If this does not work: if the checker reports the project name as `Unnamed`, step 10 was skipped; without the project object FreeCAD names the IfcProject after the internal document name.
