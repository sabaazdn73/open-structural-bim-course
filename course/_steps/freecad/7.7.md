1. Open your `tb01.ifc` of section 4 (File > Open…, **All individual IFC objects**, **Load the shape (slower)**, **Locked (IFC objects only)**).
2. File > Save IFC File As…, `template.ifc`, so that the next steps do not touch tb01.ifc.
3. In the tree, select every placed element: the columns, beams, core walls, slab, stair, pad footings, pile cap, piles and rebars (open each level and Ctrl+click or Shift+click).
4. Press Delete. FreeCAD removes the elements from the IFC file. The levels, the grid, the types (RC Column 400x400, RC Beam 300x350 downstand, Pad Footing 1800x1800x600 and the catalogue column types) and the materials stay, because nothing deletes them with the elements.
5. File > Save IFC File (Ctrl+S).
6. Check with `python -m bimcheck 7.7 template.ifc`: the materials Concrete C30/37, Concrete C25/30 and A500 must be listed, and no placed element may be left.
