1. Open `tb01.FCStd`.
2. Manage > Schedule. The **Schedule Definition** panel opens. Set **Schedule name** `Concrete volumes`.
3. Press **Add Row** six times. In the **Description** column type `Columns`, `Beams`, `Slab`, `Walls`, `Footings and caps`, `Piles`.
4. In **Property** type `Shape.Volume` on every row, and in **Unit** type `m^3`.
5. Select the building **TB-01** in the tree, select all six rows and press **Add Selection**: the **Objects** column now names the building, so each row looks inside it.
6. In **Filter** type `IfcType:Column`, `IfcType:Beam`, `IfcType:Slab`, `IfcType:Wall`, `IfcType:Footing`, `IfcType:Pile`.
7. Press OK. The schedule computes the totals: columns 6.43, beams 10.84, slab 63.06, walls 9.21, footings and cap 39.33, piles 13.57 m³.
8. Double-click the schedule in the tree to open the panel again and press **Export**. Choose **Comma-separated values (*.csv)** and save as `schedule.csv`.
9. Check with `python -m bimcheck 5.4 schedule.csv tb01.ifc`. The piles in the IFC file are faceted, about 1.8 % smaller than the true cylinders in FreeCAD, which is inside the 2 % tolerance.
