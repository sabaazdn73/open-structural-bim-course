Setup Project (exercise 1.1) made two axis objects, **Vertical Axes** and **Horizontal Axes**, joined in the axis system **Axes** inside the group Building Layout. FreeCAD exports an axis system with two sets of axes as one IfcGrid. Here you give them the TB-01 tags, lengths and positions.

1. Open `tb01.FCStd` and switch to the top view: View > Standard Views > 2 Top.
2. Select **Vertical Axes**. Check in the Data tab that **Distances** reads 0, 6000, 6000, 6000 (axes at x = 0, 6, 12, 18 m).
3. In the View tab set **Numbering Style** to `A,B,C`. These are the lettered axes A to D, parallel to Y.
4. In the Data tab set **Length** to `18000 mm` (14 m between grids 1 and 3, plus 2 m at each end) and **Placement > Position > y** to `-2000 mm`.
5. Rename the object `Grid A-D` (F2).
6. Select **Horizontal Axes**. Check that **Distances** reads 0, 7000, 7000 and that **Placement > Angle** is 90 °.
7. In the View tab set **Numbering Style** to `1,2,3`.
8. In the Data tab set **Length** to `22000 mm` and **Placement > Position > x** to `20000 mm`. Turned 90 °, these axes run from x = +20 m back to x = -2 m, at y = 0, 7 and 14 m.
9. Rename the object `Grid 1-3`.
10. Check the drawing: bubbles A to D at the bottom and top, 1 to 3 at both ends, every line 2 m past the outer grids.
11. Save and export `tb01.ifc` as before.

If this does not work: axes made one by one with Annotation > Axis are exported as loose IfcGridAxis items without an IfcGrid. Select both axis objects and use Annotation > Axis System to join them.
