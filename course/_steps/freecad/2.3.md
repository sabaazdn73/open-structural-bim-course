1. Open `tb01.FCStd`. Right-click **Level 1** and tick **Active**. The working plane moves to Level 1 (+3.600), so what you draw now lies at the top of the slab.
2. 2D Drafting > Rectangle. Type the first corner `-200`, `-200` in the X and Y boxes and press Enter, then the opposite corner `18200`, `14200` and Enter. (If **Relative** is ticked in the task panel, type the size `18400`, `14400` instead.)
3. Select the rectangle and check the Data tab: **Length** `18400 mm`, **Height** `14400 mm`, **Placement > Position** -200, -200, 3600.
4. With the rectangle selected, 3D/BIM > Slab. FreeCAD extrudes it downwards. Set the slab's **Height** to `250 mm` (top +3.600, soffit +3.350) and rename it `S-L1`.
5. Make the core opening: 3D/BIM > Generic 3D Tools > Box, click three points anywhere and a height, then in the Data tab set **Length** `2500 mm`, **Width** `2500 mm`, **Height** `450 mm` and **Placement > Position** 7750, 9250, 3250. The box reaches 100 mm past the slab on both faces.
6. Make the stair opening the same way: Length `1200 mm`, Width `5400 mm`, Height `450 mm`, Position 13000, 1000, 3250.
7. Select the core box, then Ctrl+click the slab (the host is selected last). Modify > Remove Component. The box is hidden and cut out of the slab. Do the same with the stair box.
8. Check that S-L1 is inside Level 1 and that its **Subtractions** list (Data tab, group Component) holds the two boxes. FreeCAD exports them as IfcOpeningElement voids.
9. Clear **Active** on Level 1. Save and export `tb01.ifc`.
