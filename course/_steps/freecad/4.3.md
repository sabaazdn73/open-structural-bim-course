1. Open `tb01.ifc` as in 4.1 (All individual IFC objects, Load the shape, Locked).
2. Select the 12 columns in the tree. Manage > Manage IFC Properties.
3. In **Add property set** choose **New** and type `TB01_Structural`. Check the spelling: the name is the contract.
4. With TB01_Structural selected, **Add property** > **Label**. Rename the new property `FireResistance` and set its value `R90`.
5. **Add property** > **Integer**. Rename it `DesignWorkingLife` and set `50`. Press OK. FreeCAD writes the property set into the IFC file and shows it as a property group TB01_Structural in the Data tab.
6. Repeat for the 17 beams (`R60`), the slab S-L1 (`REI60`) and the four core walls (`REI90`), each with DesignWorkingLife `50`.
7. Click one beam and check the TB01_Structural group in the property editor.
8. File > Save IFC File (Ctrl+S).
