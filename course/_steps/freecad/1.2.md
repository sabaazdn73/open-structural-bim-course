1. Open `tb01.FCStd`. In the tree, expand TB-01 Training Building > TB-01 Site > TB-01. Setup Project made Level 0 to Level 3 at 0, 3600, 7200 and 10800 mm.
2. Select **Level 3**, press F2 and rename it `Roof`.
3. Click an empty part of the 3D view so that nothing is selected (the Level tool puts the selected objects inside the new level).
4. 3D/BIM > Level. A new level appears in the tree.
5. Rename it `Foundation`. In the property editor (Data tab) open **Placement > Position** and set **z** to `-1200 mm`.
6. If Foundation is not inside TB-01, drag it onto TB-01 in the tree.
7. Check each level's **Placement > Position > z**: Level 0 `0`, Level 1 `3600 mm`, Level 2 `7200 mm`, Roof `10800 mm`. FreeCAD writes this height as the storey elevation (the Elevation attribute follows it).
8. Save, select TB-01 Training Building and export `tb01.ifc` (File > Export…, Industry Foundation Classes).
