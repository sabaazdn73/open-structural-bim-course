FreeCAD 1.1 has no purge command, and in a native IFC document the tree shows only what the elements use: unused types, materials, profiles and empty groups are in the file but not in the tree. You remove them with the IfcOpenShell library that ships with FreeCAD.

1. Copy `datasets/bloated_model.ifc` to your work folder and open the copy: File > Open with **All individual IFC objects**, **Load the shape (slower)**, **Locked (IFC objects only)**.
2. View > Panels > Python Console. Change the path of the catalogue (the types you keep) and run:
   ```python
   import ifcopenshell.api, ifcopenshell.util.element as ue
   f = FreeCAD.ActiveDocument.Proxy.ifcfile
   keep = [r.split(",")[0] for r in open("/path/to/course/datasets/column_types.csv").read().splitlines()[1:]]
   for t in f.by_type("IfcElementType"):
       if not ue.get_types(t) and t.Name not in keep:
           print("type", t.Name); ifcopenshell.api.run("root.remove_product", f, product=t)
   for m in f.by_type("IfcMaterial"):
       if f.get_total_inverses(m) == 0:
           print("material", m.Name); ifcopenshell.api.run("material.remove_material", f, material=m)
   for p in f.by_type("IfcProfileDef"):
       if f.get_total_inverses(p) == 0:
           print("profile", p.ProfileName); f.remove(p)
   for g in f.by_type("IfcGroup"):
       if not any(r.RelatedObjects for r in g.IsGroupedBy):
           print("group", g.Name); ifcopenshell.api.run("group.remove_group", f, group=g)
   FreeCAD.ActiveDocument.Modified = True
   ```
3. The console lists what it removed: two types (Temp Beam, Old Column 250x250), two materials, one profile and one group.
4. Read the list before you save. Types used by elements and the catalogue types stay.
5. File > Save IFC File As…, `purged_model.ifc`.
