In FreeCAD each element keeps the size you give it, so a clean frame comes from modelling every element to its true extent: columns and walls stop at +3.350, beams stop at the column faces, the slab sits on top.

1. Open `tb01.FCStd`. Select all 12 columns and check in the Data tab that **Height** reads `3350 mm` (it shows one value when all agree).
2. Select the four core walls: **Height** `3350 mm`, **Width** `250 mm`. The west and east walls run from y 9250 to 11750, between the south and north walls.
3. Select the beams along X: **Length** `5600 mm`; the beams along Y: **Length** `6600 mm`. A beam of 6000 or 7000 mm runs into the columns.
4. Select the slab: **Height** `250 mm`, base rectangle at z = 3600.
5. To see an overlap, select two elements and use Modify > Intersection. If the result has a volume, the two elements overlap; fix the size or position, then delete the intersection object.
6. Look at the volumes in Manage > Manage IFC Quantities: the **Volume** column shows each element. Expected totals: columns 6.43 m³, beams 10.84 m³, core walls 9.21 m³, slab 63.06 m³.
7. Close the dialog with Cancel (you add quantities in exercise 7.8). Save and export `tb01.ifc`.
