Drawings come from the classic model `tb01.FCStd` of sections 1 to 3. You cut it with a section plane, turn the cut into a BIM 2D drawing, annotate it with Draft tools and export it as a flattened SVG, which keeps every text as text.

1. Open `tb01.FCStd`. In the status bar at the bottom, set the Draft annotation scale to `1:100`.
2. Select Level 0 and Level 1 in the tree. Annotation > Section Plane. In the Data tab set **Placement > Position** 9000, 7000, 3200 and leave the angle at 0: a horizontal cut between the beam soffit (+3.000) and the slab soffit (+3.350), looking down. Rename it `Section Level 1 plan`.
3. With the section plane selected, Annotation > Create 2D Views > 2D Drawing. FreeCAD makes a drawing with **Viewed lines** and **Cut lines** laid flat on the ground plane. Rename it `Level 1 framing plan`.
4. Annotation > Horizontal Dimension, with **Global** ticked: 0, -2500, 0 to 6000, -2500, 0, then click below to place the line. Repeat for 6000 to 12000 and 12000 to 18000, and once more from 0 to 18000 at y -3500 for the overall size.
5. Annotation > Vertical Dimension: 0 to 7000 and 7000 to 14000 at x -2500, and 0 to 14000 at x -3500.
6. Select all dimensions and in the View tab set **Font Size** `250 mm` (the SVG exporter writes the font size as it is, and 1:100 needs 2.5 mm text).
7. Drag the dimensions into the drawing Level 1 framing plan in the tree.
8. Select Viewed lines, Cut lines, the dimensions and the two axis objects Grid A-D and Grid 1-3 (they carry the bubbles A to D and 1 to 3).
9. File > Export…, set the file type to **Flattened SVG (*.svg)** and save as `plan.svg`.
10. Open `plan.svg` in a web browser or Inkscape and check the bubbles and the dimensions 6000 and 7000 (FreeCAD writes them as 6000.00 mm).

If this does not work: Annotation > New Page and New View put the same section plane on a TechDraw sheet, but in our tests with FreeCAD 1.1.3 the SVG and PDF exported from TechDraw lost the texts of the BIM view, so the checker found no grid bubbles. Use the flattened SVG for the check.
