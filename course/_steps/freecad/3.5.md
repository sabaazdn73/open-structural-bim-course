1. Open `tb01.FCStd`. Select the 12 columns, 17 beams, 4 core walls, the slab S-L1 and the stair ST-1 (Ctrl+click in the tree).
2. Manage > Material. Press **New Material**, set **Name** `Concrete C30/37` and press OK. Back in the list, pick Concrete C30/37 and press OK: the selected elements get it (Data tab, group Component, **Material**).
3. Select the 12 pad footings, PC-1 and the four piles. Manage > Material, **New Material** `Concrete C25/30`, then assign it the same way.
4. Check that the six rebar objects have **A500** (exercise 3.4).
5. Select the elements of step 1. Manage > Manage IFC Properties. In **Add property set** choose **New** and type `Pset_ConcreteElementGeneral`. Do not pick the preset called Concrete Element Genera: FreeCAD 1.1.3 lists it with a typing error and the checker would not find it.
6. With the new property set selected, use **Add property** and pick **Label**. Rename the new property `StrengthClass` and give it the value `C30/37`. Add a second **Label** property `ExposureClass` with the value `XC1`. Press OK.
7. Select the footings, PC-1 and the piles and do the same with `C25/30` and `XC2`.
8. Save and export `tb01.ifc`. Each concrete element now has an IfcMaterial and Pset_ConcreteElementGeneral.
