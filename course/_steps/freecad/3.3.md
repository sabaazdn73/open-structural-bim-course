1. Open `tb01.FCStd`. Right-click **Foundation** and tick **Active**.
2. Pile cap: 3D/BIM > Column with **Length** `4000 mm`, **Width** `4000 mm`, **Height** `1000 mm`. Tick **Global** and type the point 9000, 10500, -1600, Enter.
3. Rename it `PC-1`. In the Data tab set **Ifc Type** `Footing`, then **Predefined Type** `PILE_CAP`.
4. Piles: switch to View > Workbench > Part and use Part > Primitives > Cylinder. Set **Radius** `300 mm`, **Height** `12000 mm` and **Placement > Position** 7800, 9300, -13600.
5. Make three more cylinders the same way (or Edit > Duplicate Selection and change the position): 10200, 9300; 7800, 11700; 10200, 11700, all at z -13600. The tops are at -1.600, the underside of the cap.
6. Switch back to the BIM workbench. Select the four cylinders and use 3D/BIM > Column. FreeCAD makes one structure from each cylinder.
7. Rename them `P-1` to `P-4`. Select all four and set **Ifc Type** `Pile` and **Predefined Type** `BORED`.
8. Check that PC-1 and the four piles are inside the Foundation level. Clear **Active**, save and export `tb01.ifc`.

If this does not work: do not make the piles from a Draft circle. In FreeCAD 1.1.3 the IFC export of a circle-based structure with Ifc Type Pile stops with "Cannot create polygon because less than two vertices are given". Piles made from a Part cylinder export as faceted solids, about 2 % smaller in volume than a true cylinder.
