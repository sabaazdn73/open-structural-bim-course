1. Open `tb01.FCStd`. Right-click **Foundation** and tick **Active**. The working plane moves to -1.200, the underside of the footings.
2. 3D/BIM > Column. Set **Length** `1800 mm`, **Width** `1800 mm`, **Height** `600 mm` and tick **Continue**.
3. Click the 12 grid intersections (Snap Intersection), or type each point with **Global** ticked: X and Y of the grid, Z `-1200`. Each footing is centred under its column, from -1.200 to -0.600. Press Esc.
4. FreeCAD names these objects Beam (they are longer than they are high). Rename them `F-A1` ... `F-D3`, like the columns above them.
5. Select the 12 footings. In the Data tab set **Ifc Type** to `Footing`.
6. With the 12 still selected, set **Predefined Type** (group IFC Attributes) to `PAD_FOOTING`. The default after the change is CAISSON_FOUNDATION, which is wrong here.
7. Check that the footings are inside the Foundation level. Clear **Active**, save and export `tb01.ifc`.
