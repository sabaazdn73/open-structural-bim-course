1. Open `tb01.FCStd`. Set the annotation scale in the status bar to `1:20`.
2. Select F-A1, C-A1 and the rebars of exercise 3.4. Annotation > Section Plane.
3. Set **Placement > Angle** `90 °`, **Axis** 1, 0, 0, **Position** 0, 0, -600: a vertical cut through the middle of F-A1 and C-A1. In the View tab set **Display Length** and **Display Height** to `3000 mm`, so the plane covers only the footing and the foot of the column. Rename it `Detail F-A1`.
4. With the plane selected, Annotation > Create 2D Views > 2D Drawing. Rename the drawing `Detail F-A1`.
5. Annotation > Text below the drawing: `TYPICAL COLUMN FOOTING DETAIL`.
6. Annotation > Text beside it, one note per text: `Concrete C25/30, exposure XC2`, `Steel A500`, `Bottom mesh Ø16 @ 150 each way`, `50 mm cover`. Annotation > Leader can point a note to the bars.
7. Set **Font Size** `60 mm` for the notes in the View tab (3 mm at 1:20). Drag them into the drawing.
8. Select Viewed lines, Cut lines and the texts. File > Export…, **Flattened SVG (*.svg)**, save as `detail.svg`.
