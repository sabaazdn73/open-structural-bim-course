1. In **Geometry and Materials > Profiles**, add an **IfcRectangleProfileDef** `RC 4000x1000` (**XDim** `4.0`, **YDim** `1.0`) and an **IfcCircleProfileDef** `Pile 600` (**Radius** `0.3`).
2. With the **Footing Tool**, open the **Type Manager** and click **Create New IfcFootingType**: **Name** `Pile Cap 4000x4000x1000`, **Predefined Type** PILE_CAP, **Representation** Extruded Profile, **Profile** RC 4000x1000.
3. Keep **Foundation** as the default container and **Axis** bottom centre. Pick the new type in the tool header.
4. Click **Add**, click two points roughly along X and press Enter. Set **Location** `7.0`, `10.5`, `-1.6` and **Length** `4.0`, **Update**. The cap spans x 7.0 to 11.0, y 8.5 to 12.5, from -1.600 to -0.600. Name it `PC-1`.
5. Pick the **Pile Tool**. Click "No IfcPileTypes Found" and **Create New IfcPileType**: **Name** `Bored Pile 600`, **Predefined Type** BORED, **Representation** Extruded Profile, **Profile** Pile 600.
6. Piles extrude upwards like columns. In the tool header set **Axis** mid-depth centre and **H** `12`.
7. Click **Add**, click once in the viewport and right-click to stop. Set **Location** `7.8`, `9.3`, `-13.6`: the pile runs from -13.600 up to the underside of the cap at -1.600. Name it `P-1`.
8. Copy it Shift+D, X, `2.4`, Enter (P-2 at x 10.2). Select both and copy them Shift+D, Y, `2.4`, Enter (P-3, P-4 at y 11.7).
9. Check that the cap and the four piles are in **Foundation** (**Spatial Container**). Save with **File > Save IFC Project**.
