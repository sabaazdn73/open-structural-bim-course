1. Columns, beams, the slab and the walls already have **Concrete C30/37**: their types took the first material in the file (2.1). Check one: **Geometry and Materials > Object Materials** shows it as the inherited material.
2. In **Geometry and Materials > Materials**, click **+** (**Add Material**) and add `Concrete C25/30`, Category `concrete`.
3. Select one pad footing. In **Object Materials**, click the pencil (**Enable Editing Assigned Material**), then the pencil on the profile item (**Enable Editing Material Set Item**). Choose **Material** Concrete C25/30, click **Save Changes**, then the check mark. The profile set belongs to the type, so all 12 footings change.
4. Do the same with the pile cap and with one pile.
5. Give the stair a material too: select it, choose IfcMaterial and Concrete C30/37 in **Object Materials** and click **+** (**Assign Material**).
6. Deselect all (Alt+A). In **Project Overview > Grouping and Filtering > Search**, click the funnel (**Edit Filter Query**), type `IfcColumn, IfcBeam, IfcSlab, IfcWall` and click **Search**.
7. Go to **Object Information > Misc > Bulk Property Editor > Bulk Add / Edit Custom Properties**. Click **Add Property to Edit** twice and fill in:
   - `Pset_ConcreteElementGeneral`, `StrengthClass`, `C30/37`, IfcLabel
   - `Pset_ConcreteElementGeneral`, `ExposureClass`, `XC1`, IfcLabel
8. Click **Apply Changes**. Bonsai reports how many elements changed.
9. Deselect all, search `IfcFooting, IfcPile`, change the values to `C25/30` and `XC2` and click **Apply Changes** again.
10. Check one footing in **Object Information > Object > Property Sets**. Save with **File > Save IFC Project**.
