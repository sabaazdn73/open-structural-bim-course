1. Open your TB-01 model. Choose **File > Save IFC Project As...** and save it as `option_A.ifc`. Do not change anything in it.
2. Choose **File > Save IFC Project As...** again and save it as `option_B.ifc`. You are now working in option B.
3. Add an **IfcRectangleProfileDef** `RC 400x500` (**XDim** `0.40`, **YDim** `0.50`) in **Geometry and Materials > Profiles**.
4. With the **Beam Tool**, open the **Type Manager** and click **Create New IfcBeamType**: **Name** `RC Beam 400x500 downstand`, **Predefined Type** BEAM, **Representation** Extruded Profile, **Profile** RC 400x500.
5. Select beam **B-2/BC**. In **Object Information > Object > Type**, click the pencil (**Enable Editing Type**), choose IfcBeamType and **RC Beam 400x500 downstand**, and click the check mark (**Assign Type**).
6. Bonsai rebuilds the beam with the new profile and keeps its axis at the top centre, so it still hangs from +3.350 and now reaches +2.850, 400 wide.
7. Save with **File > Save IFC Project**.
8. Go to **Quality and Coordination > Quality Control > Diff**. Set **Active File** to the new file (option B is open) and pick `option_A.ifc` as the **Old IFC File** with the folder icon.
9. Click **Execute IFC Diff** and save the report as `diff.json`. Click the eye icon (**Visualise Diff**): only B-2/BC is coloured as changed.
10. Open `diff.json` in a text editor: it lists one changed element and what changed.
