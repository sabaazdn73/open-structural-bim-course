Each of the four problems can be found with a search query in Bonsai. The queries use the IfcOpenShell selector syntax.

1. Open `datasets/unhealthy_model.ifc` and save your copy as `fixed_model.ifc` (**File > Save IFC Project As...**).
2. In **Project Overview > Grouping and Filtering > Search**, click the funnel (**Edit Filter Query**). For each query below, deselect all (Alt+A), type the query, click OK and click **Search**:
   - `IfcColumn, IfcBeam, IfcSlab, IfcWall, location=NULL` finds the element in no level: beam B-2/CD.
   - `IfcColumn, IfcBeam, IfcSlab, IfcWall, material=NULL` finds the element without a material: the slab.
   - `IfcColumn, IfcBeam, IfcSlab, IfcWall, Name=""` finds the element without a name: a core wall.
3. For the duplicate, look at **Spatial Decomposition**: click Level 0 and the element list shows 13 columns instead of 12. In the Outliner, filter for `C-`: one column appears twice (Blender adds ".001" to the second name).
4. Fix the duplicate: select the column with ".001", press X and choose **IFC Delete**.
5. Fix the beam: select B-2/CD, open **Object Information > Object > Spatial Container**, click the pencil (**Enable Editing Container**), choose **Level 1** and click the check mark (**Assign Container**).
6. Fix the slab: select it, open **Geometry and Materials > Object Materials**, choose IfcMaterial and **Concrete C30/37**, and click **+** (**Assign Material**).
7. Fix the wall: it sits on the east side of the core (x 10.25 to 10.5). In **Object Attributes**, click **Edit**, set **Name** `W-Core-E` and click **Save Attributes**.
8. Run the three searches again: each finds nothing. Click Level 0 in **Spatial Decomposition**: 12 columns.
9. Save with **File > Save IFC Project**.
