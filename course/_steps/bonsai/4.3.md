1. Deselect all (Alt+A). In **Project Overview > Grouping and Filtering > Search**, set the filter query (funnel icon) to `IfcColumn` and click **Search**.
2. Go to **Object Information > Misc > Bulk Property Editor > Bulk Add / Edit Custom Properties**. Click **Add Property to Edit** twice and fill in the rows:
   - `TB01_Structural`, `FireResistance`, `R90`, IfcLabel
   - `TB01_Structural`, `DesignWorkingLife`, `50`, IfcInteger
3. Click **Apply Changes**. Bonsai reports "12 elements changed".
4. Deselect all, search `IfcBeam`, change FireResistance to `R60` and click **Apply Changes**.
5. Do the same for `IfcSlab` (`REI60`) and `IfcWall` (`REI90`). DesignWorkingLife stays 50.
6. Check one element of each class in **Object Information > Object > Property Sets**: TB01_Structural with both properties. The name must be exactly `TB01_Structural`.
7. Save with **File > Save IFC Project**.
