Bonsai has a Git panel. It needs Git installed on your computer (git-scm.com); on Windows the panel offers **Install Git**.

1. Put `tb01.ifc` in its own folder, for example `TB01-work`. Do not make your whole user folder a repository.
2. If you have never used Git on this computer, set your name once in a terminal: `git config --global user.name "Your Name"` and `git config --global user.email "you@example.org"`.
3. Open `tb01.ifc`. The best moment is right after section 1 (levels and grid); if you are further on, start now and commit after your next change.
4. Go to **Project Overview > Project Info > Git** and click **Create 'TB01-work' repository**.
5. Click **Add 'tb01.ifc' to repository**. Bonsai makes the first commit, "Added tb01.ifc".
6. Do the next part of the work (for example section 2, or the quantities of 7.8) and save with **File > Save IFC Project**. The Git panel says "Saved changes have not been committed".
7. Click **Show uncommitted changes** to see the new elements in colour.
8. Type a message that says what changed, for example `Columns, walls, slab and beams`, and click **Commit changes**.
9. Repeat after each section. The list at the bottom of the panel shows every commit with its message and date.
10. Run the checker on the folder: `python -m bimcheck 7.3 TB01-work`.
