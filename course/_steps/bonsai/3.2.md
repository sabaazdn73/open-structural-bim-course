The Footing Tool extrudes its profile horizontally, like a beam: the profile is the footing's cross-section (width x depth) and the length is the third dimension.

1. In **Geometry and Materials > Profiles**, add an **IfcRectangleProfileDef** named `RC 1800x600` with **XDim** `1.8` and **YDim** `0.6`.
2. Pick the **Footing Tool** (click and hold the Column Tool button). Click "No IfcFootingTypes Found" and **Create New IfcFootingType**: **Name** `Pad Footing 1800x1800x600`, **Predefined Type** PAD_FOOTING, **Representation** Extruded Profile, **Profile** RC 1800x600.
3. Make **Foundation** the default container. In the tool header set **Axis** to **bottom centre**.
4. Click **Add** (Shift+A), click two points roughly along X and press Enter.
5. In the sidebar (N) > **Item** set **Location** X `-0.9`, Y `0`, Z `-1.2`. Set **Length** `1.8` in the tool settings and click **Update**. The footing is centred under C-A1, from -1.200 to -0.600.
6. Rename it `F-A1` in the Outliner.
7. Copy it Shift+D, X, `6`, Enter, three times. Select the four footings and copy them Shift+D, Y, `7`, Enter, twice.
8. Rename them F-A1 ... F-D3 to match the columns above.
9. The predefined type PAD_FOOTING is stored on the type, and every footing inherits it. Bonsai hides the occurrence's own PredefinedType field for that reason.
10. Save with **File > Save IFC Project**.
