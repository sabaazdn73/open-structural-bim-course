In Bonsai a quantity schedule is two steps: compute base quantities into the model, then export them with the spreadsheet tool. The quantity rule that uses IfcOpenShell geometry gives volumes for columns, beams, slabs, walls and footings, but not for piles, so you quantify the piles by hand.

1. Deselect all (Alt+A). Go to **Costing and Scheduling > Quantity Take-off**. The panel says "Quantifying All Objects".
2. Choose the rule **IFC4 Base Quantities - IfcOpenShell** and click **Perform Quantity Take-off**. Each element gets its Qto_...BaseQuantities set with NetVolume.
3. Select the four piles (Search `IfcPile`). In **Manual Quantification**, set **Calculator** IfcOpenShell, **Function** Volume: Net Volume, and type `Qto_PileBaseQuantities` and `NetVolume` in the two name fields. Click **Calculate Single Quantity**.
4. Go to **Quality and Coordination > Collaboration > Spreadsheet Import/Export**. Tick **Load from Memory** and open the settings (gear icon): **Format** csv.
5. Click the funnel (**Edit Filter Query**) and type `IfcColumn, IfcBeam, IfcSlab, IfcWall, IfcFooting, IfcPile`.
6. Click **Add CSV Attribute** three times and fill in each row (attribute, then header):
   - `class`, `Class`
   - `Name`, `Mark`
   - `/Qto_.*BaseQuantities/.NetVolume`, `Volume (m3)`
7. Click **Export IFC to CSV** and save as `schedule.csv`. Open it: one row per element with its class, mark and volume.
8. Do not add a column with the type name: the checker reads "Pile Cap" as a pile.
9. Save the model too (**File > Save IFC Project**): the checker compares the schedule with the volumes in `tb01.ifc`.
