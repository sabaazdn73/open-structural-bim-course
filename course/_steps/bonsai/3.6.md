1. Deselect all (Alt+A). In **Project Overview > Grouping and Filtering > Search**, set the filter query (funnel icon) to `IfcColumn` and click **Search**: the 12 columns are selected.
2. Open **Project Overview > Grouping and Filtering > Groups** and click the pencil (**Load Groups**).
3. Click **+** (**Add New Group**). A group named "Unnamed" appears in the list.
4. With the group active, click its pencil (**Enable Editing Group**), set **Name** `Ground Floor Columns` and click **Save Group**.
5. With the columns still selected, click the arrow icon (**Assign Group**). The group now holds the 12 columns.
6. Deselect all, search `IfcBeam` (17 beams), add a second group named `Level 1 Beams` and assign the beams the same way.
7. Test them: deselect all and click the select icon (**Select Group elements**) of each group.
8. Save with **File > Save IFC Project**.
