In Bonsai every column, beam and footing you placed with a tool already uses a type, so this exercise is a check and a tidy-up.

1. Select a column. **Object Information > Object > Type** shows **RC Column 400x400**.
2. Click the select icon next to the type name (**Select Similar Type**): Bonsai selects every occurrence of the type. All 12 columns light up.
3. Do the same for a beam (**RC Beam 300x350 downstand**, 17) and a pad footing (**Pad Footing 1800x1800x600**, 12). The pile cap has its own type and does not count here.
4. If an element has no type (for example a footing you made from a cube), select it, click the pencil in the **Type** panel (**Enable Editing Type**), choose the class and the type, and click the check mark (**Assign Type**).
5. To rename a type, open the tool's **Type Manager**, click the gear next to the type and choose **Rename Type**.
6. Try the point of types: in **Geometry and Materials > Profiles**, edit **RC 400x400** to 0.5 x 0.5. All 12 columns change at once. Set it back to 0.4 x 0.4.
7. Save with **File > Save IFC Project**.
